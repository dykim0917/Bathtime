# Bathtime Spot Content Output Templates

## 찾아봤다

Use when based on public research.

Title examples:
- 서울에서 조용히 쉬기 좋은 사우나를 찾아봤다
- 외부인도 이용 가능한 호텔 사우나가 있을까?
- 프라이빗 스파룸은 돈값을 할까?

## 다녀왔다

Use only when firsthand visit notes are provided.

Title examples:
- ○○ 사우나에 다녀왔다
- 욕조 있는 숙소를 써보고 느낀 점

## 업데이트했다

Use when refreshing existing content.

Title examples:
- 외부인 이용 가능한 서울 사우나 리스트 업데이트
- 2026년 기준 욕조 있는 숙소 체크리스트

## 제보받았다

Use when based on user submission.

Title examples:
- 제보받은 서울 사우나 리스트
- 독자 제보로 정리한 조용한 스파 공간
