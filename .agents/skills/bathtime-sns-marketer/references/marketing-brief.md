# 바스타임 초기 마케팅 운영 브리프

## Mission

비공개 테스트 기간 동안 바스타임이 실제로 존재하는 브랜드처럼 보이게 만들고, 테스트 참여자와 초기 피드백을 모은다.

대규모 유입보다 중요한 목표:

1. 브랜드 계정이 비어 보이지 않게 만들기
2. 핵심 메시지 반복 각인
3. 테스트 참여자 모집
4. 초기 피드백 수집
5. 앱의 가치 이해 여부 검증

## Product Definition

바스타임은 오늘 몸 상태와 가능한 방식에 맞춰 샤워·족욕·욕조 루틴을 안내하는 생활형 셀프케어 앱이다.

앱은 다음을 안내한다.

- 온도
- 시간
- 진행 순서
- 안전 안내
- 타이머 진행
- 완료 후 기록

바스타임은 의료 진단이나 치료 서비스가 아니다. 일상 속 샤워와 목욕을 조금 더 가볍고 안전하게 정리해주는 루틴 가이드다.

## Core Messages

대표 메시지:

> 그냥 씻기 아쉬운 날에

서브 메시지:

> 피곤한 날, 잠 안 오는 밤, 운동 후 뻐근한 몸까지. 오늘 몸에 맞는 샤워·목욕 루틴을 가볍게 따라가요.

설명형 메시지:

> 매일 그냥 씻고 끝내던 시간을, 오늘 몸 상태에 맞는 루틴으로 바꿔보세요. 샤워만으로도 충분하고, 필요하면 족욕이나 욕조 루틴으로 확장할 수 있습니다.

## Positioning

기존 방향:

- 욕조에서 잘 쉬게 해주는 앱

현재 방향:

- 그냥 씻고 끝내던 시간을, 오늘 몸에 맞는 루틴으로 바꿔주는 앱

한국 시장 기준:

- 입구: 샤워
- 확장: 족욕, 욕조
- 감성 확장: 무드 루틴, 입욕제, 제품 추천

## Target Situations

- 퇴근 후 몸이 무거운 사람
- 잠이 잘 안 오는 밤이 있는 사람
- 운동 후 몸이 뻐근한 사람
- 그냥 씻고 눕기엔 몸이 찌뿌둥한 사람
- 샤워 시간을 조금 더 잘 활용하고 싶은 사람
- 입욕제나 바디워시는 좋아하지만 루틴은 모르는 사람

핵심 인식:

사용자는 "오늘 어떻게 씻지?"라고 고민하지 않는다. 대부분 그냥 씻는다. 콘텐츠는 "씻는 법을 알려준다"가 아니라 "그냥 씻던 시간을 이렇게 바꿔볼 수 있다"는 제안이어야 한다.

## Private Test Goals

숫자 목표:

- 테스트 신청자: 30명
- 실제 사용: 15명
- 피드백 회수: 10명
- 루틴 완료 경험: 5명 이상

## Feedback Questions

1. 이 앱이 뭐 하는 앱인지 바로 이해됐나요?
2. 샤워만으로도 쓸 수 있다고 느껴졌나요?
3. 씻는 시간이 더 복잡해졌다고 느꼈나요, 아니면 정리됐다고 느꼈나요?
4. 루틴 상세 화면에서 읽을 게 많다고 느꼈나요?
5. 실제로 타이머를 시작해봤나요?
6. 완료 후 기록 화면은 자연스러웠나요?
7. 다시 쓸 것 같은 상황이 떠올랐나요?

점수형:

- 이해 쉬움: 1~5점
- 복잡하지 않음: 1~5점
- 다시 쓸 가능성: 1~5점
- 추천하고 싶음: 1~5점

## Weekly Workflow

월요일:

- 이번 주 콘텐츠 주제 3개 선정
- 지난주 반응 확인
- 테스트 신청자 수 확인

화요일~목요일:

- 콘텐츠 작성
- 이미지/카드뉴스 제작 요청
- 게시물 업로드

금요일:

- 테스트 모집 재공지
- 받은 피드백 정리
- 다음 주 개선 포인트 기록

일요일:

- 1주 요약 작성
- 다음 주 콘텐츠 방향 정리

## Success Criteria

- SNS 계정에 최소 6개 이상의 게시물이 있다.
- 프로필에서 테스트 신청 링크가 바로 보인다.
- 랜딩페이지와 SNS 메시지가 같은 방향을 말한다.
- 테스트 신청자가 30명 이상이다.
- 실제 피드백이 10개 이상 모인다.
- 사용자가 "샤워만으로도 쓸 수 있다"고 이해한다.
- 사용자가 "그냥 씻는 시간을 조금 다르게 써볼 수 있다"고 느낀다.
