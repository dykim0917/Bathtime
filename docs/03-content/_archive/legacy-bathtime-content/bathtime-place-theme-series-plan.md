# Bathtime Place Theme Series Plan

## Purpose

바스타임의 장소형 콘텐츠는 당분간 단일 장소 리뷰보다 주제형 시리즈로 쌓는다.

지도 검색으로도 장소 이름은 찾을 수 있지만, 바스타임은 그보다 앞단의 질문을 맡는다. 어떤 목욕·사우나·스파 경험인지, 어떤 사람에게 맞는지, 방문 전 무엇을 확인해야 하는지, 후보를 볼 때 어떤 불확실성을 남겨야 하는지를 정리한다.

## Content Types

### Culture Note

주제의 배경과 감각을 설명한다.

예:

- 해수찜질은 어떤 목욕 문화인가
- 불한증막은 찜질방과 어떻게 다르게 느껴지는가
- 숙박형 온천 지역에서는 목욕이 여행의 어떤 부분이 되는가

역할:

- 용어와 문화적 맥락 정리
- 바스타임다운 관점 제시
- 특정 장소 추천 없이 주제의 매력과 주의점 설명

### Spot Guide

주제에 맞는 공간을 찾는 기준과 후보 탐색 순서를 정리한다.

예:

- 해수찜질을 할 수 있는 곳을 찾을 때 확인할 것들
- 외부인 이용 가능한 호텔 사우나 여부는 어디서 확인할까
- 가족형 워터파크 스파를 볼 때 먼저 나눠볼 기준

역할:

- 확인 순서 제시
- 후보 포함 기준 정의
- 출처별 신뢰도와 한계 표시
- 추천 순위나 직접 방문 후기처럼 보이지 않게 관리

### Candidate Guide

지역별·주제별 후보를 묶되, 추천이나 순위가 아니라 탐색 후보로 다룬다.

예:

- 전국에서 해수찜질을 찾아볼 때 먼저 확인할 지역과 후보
- 숙박형 온천 지역을 볼 때 나눠볼 권역
- 불한증막을 찾을 때 확인해볼 수 있는 공개 후보

역할:

- 장소 후보를 구조화
- 마지막 확인일과 확인 필요 항목 표시
- 공식 정보, 지도/예약 정보, 후기 패턴, 제보를 분리

### Single Spot Content

특정 장소 하나를 다룬다.

직접 방문, 신뢰 가능한 제보, 사진 권리, 운영 조건 확인이 충분할 때만 진행한다. 지금 단계에서는 대량 생산 대상이 아니라 나중에 신뢰도를 올리는 프리미엄 카드로 둔다.

## Series Shape

주제 하나는 보통 아래 순서로 기획한다.

1. Culture Note: 이 주제가 무엇인지, 왜 바스타임이 다루는지 설명한다.
2. Spot Guide: 방문 전 확인 기준과 검색 순서를 정리한다.
3. Candidate Guide: 지역별·유형별 후보를 추천이 아닌 탐색 목록으로 묶는다.
4. Single Spot Content: 직접 방문 또는 충분한 제보가 있는 곳만 단일 장소 콘텐츠로 전환한다.

모든 주제가 4단계까지 갈 필요는 없다. 초반에는 1~2단계만으로도 충분하다.

## Content Candidate Bank

이 섹션은 장소형 콘텐츠 후보 은행이다. 각 항목은 하나의 단일 장소 리뷰가 아니라, Culture Note, Spot Guide, Candidate Guide로 확장할 수 있는 주제 단위다.

우선순위 기준:

- `A`: 바스타임 관점과 검색 수요가 모두 강하고, 직접 방문 없이도 기준 콘텐츠로 시작하기 좋음
- `B`: 후보 리스트나 지역별 확장이 좋지만 리서치 부담이 있음
- `C`: 흥미롭지만 안전, 법적 표현, 이미지 권리, 직접 경험 부족 때문에 신중히 다뤄야 함

### 물의 성격

#### 해수찜질

- Priority: `A`
- Culture Note: 바닷물과 찜질이 만나는 목욕 문화
- Spot Guide: 해수찜질 장소를 찾을 때 확인할 것들
- Candidate Guide: 전국 해수찜질 후보를 권역별로 정리
- Checks: 계절성, 운영 여부, 예약/현장 접수, 가족/혼자 이용감, 물·찜질 방식, 사진 권리

#### 해수탕 / 해수 사우나

- Priority: `A`
- Culture Note: 바닷물을 목욕탕에서 쓰는 방식
- Spot Guide: 해수탕이라고 적힌 곳을 볼 때 확인할 것들
- Candidate Guide: 바닷가 도시와 도심 해수탕 후보
- Checks: 실제 해수 사용 여부 표현, 탕 종류, 수질 관리 안내, 해수찜질과의 차이

#### 온천수 대욕장

- Priority: `A`
- Culture Note: 온천수로 씻고 쉬는 경험이 다른 이유
- Spot Guide: 온천수 대욕장을 볼 때 확인할 것들
- Candidate Guide: 지역별 온천 대욕장 후보
- Checks: 온천수 표기 근거, 공용탕/객실탕 구분, 당일 이용 가능 여부, 계절성

#### 탄산온천 / 탄산수 사우나

- Priority: `B`
- Culture Note: 물의 감각이 목욕 경험을 바꾸는 방식
- Spot Guide: 탄산온천 표기를 볼 때 확인할 것들
- Candidate Guide: 탄산온천 또는 탄산탕 후보
- Checks: 자연 탄산/인공 탄산 표현, 탕 온도, 이용 시간, 피부·혈액순환 효능 단정 금지

#### 유황온천 / 광물성 온천

- Priority: `B`
- Culture Note: 냄새와 질감이 강한 온천 경험
- Spot Guide: 유황온천이나 광물성 온천을 볼 때 확인할 것들
- Candidate Guide: 지역별 유황온천 후보
- Checks: 성분 표시, 피부 질환 효능 표현 금지, 냄새 민감도, 환기, 가족 동행 적합성

#### 약수탕 / 광천수 목욕

- Priority: `C`
- Culture Note: 물의 이름이 장소의 기억이 되는 방식
- Spot Guide: 약수탕·광천수 목욕 정보를 볼 때 확인할 것들
- Candidate Guide: 오래된 약수탕 후보
- Checks: 공식 수질/성분 근거, 오래된 정보 여부, 의료 효능 표현 금지

### 열의 방식

#### 불한증막

- Priority: `A`
- Culture Note: 뜨거운 방에서 쉬는 방식의 차이
- Spot Guide: 불한증막을 찾을 때 확인할 시설과 안전 조건
- Candidate Guide: 지역별 불한증막 후보
- Checks: 고온 노출, 휴게공간, 샤워/탕 구성, 운영 시간, 후기 패턴

#### 한증막

- Priority: `A`
- Culture Note: 한증막이라는 이름이 가리키는 전통적 찜질 감각
- Spot Guide: 한증막을 볼 때 확인할 것들
- Candidate Guide: 한증막 후보를 지역별로 정리
- Checks: 불가마와의 구분, 고온/저온 방 구성, 휴식 공간, 초심자 주의

#### 숯가마

- Priority: `A`

#### 황토방

- Priority: `B`
- Culture Note: 황토방은 왜 따뜻하고 오래 머무는 공간처럼 느껴질까
- Spot Guide: 황토방이 있는 찜질방을 볼 때 확인할 것들
- Candidate Guide: 황토방 중심 찜질 공간 후보
- Checks: 방 온도, 바닥 형태, 수면/휴식 가능 여부, 위생, 과장 효능 금지

#### 소금방

- Priority: `B`
- Culture Note: 소금방에서 기대하는 감각과 실제 확인할 것
- Spot Guide: 소금방이 있는 찜질방을 볼 때 확인할 것들
- Candidate Guide: 소금방 후보
- Checks: 소금방 구성, 온도, 습도, 호흡기·피부 효능 단정 금지, 관리 상태

#### 맥반석방 / 게르마늄방 / 자수정방

- Priority: `B`
- Culture Note: 광물 이름이 붙은 찜질방을 어떻게 읽을까
- Spot Guide: 광물 테마 찜질방을 볼 때 확인할 것들
- Candidate Guide: 맥반석·게르마늄·자수정방 후보
- Checks: 테마명과 실제 시설 구분, 효능 표현 금지, 온도, 휴게공간

#### 편백방 / 소나무방 / 삼림욕방

- Priority: `A`
- Culture Note: 나무 향과 따뜻한 방이 만드는 쉬는 감각
- Spot Guide: 편백방이나 삼림욕방을 볼 때 확인할 것들

#### 아이스방 / 냉방

- Priority: `B`
- Culture Note: 뜨거운 방 뒤에 차가운 방이 있는 이유
- Spot Guide: 아이스방을 이용할 때 확인할 것들
- Candidate Guide: 아이스방이 있는 대형 찜질방 후보
- Checks: 고온-저온 반복 주의, 안전 안내, 어린이/고령자 동행, 체류 시간

#### 건식 사우나

- Spot Guide: 건식 사우나를 볼 때 확인할 것들
- Candidate Guide: 건식 사우나 후보
- Checks: 온도, 좌석 구조, 물 반입, 휴식 공간, 사우나만 있고 탕이 약한 경우

- Candidate Guide: 온천 지역별 후보 프레임
- Checks: 객실 욕조/공용탕 구분, 온천수 여부 표현, 대욕장 운영, 숙박 조건, 계절성

- Candidate Guide: 서울·강원·제주 등 지역별 욕조 숙소 후보
- Checks: 전 객실/일부 객실 여부, 욕조 크기, 입욕제 가능 여부, 온수 용량, 프라이버시

## Editorial Rules

- `추천 TOP`, `꼭 가야 할`, `최고`, `검증 완료`를 쓰지 않는다.
- 직접 방문하지 않은 글은 방문 후기처럼 쓰지 않는다.
- 후보는 `찾아볼 만한 후보`, `확인해볼 곳`, `탐색 후보`로 표현한다.
- 특정 장소 정보는 마지막 확인일을 남긴다.
- 공식 정보, 지도/예약 플랫폼, 후기 패턴, 사용자 제보를 한 문단 안에 섞지 않는다.
- 내부 사진이나 공식 이미지는 권리 확인 전 사용하지 않는다.
- 장소 콘텐츠의 기본 목적은 “좋아 보이는 곳을 추천”하는 것이 아니라 “나에게 맞는 쉼의 조건을 확인하게 하는 것”이다.

Working title:

호텔 사우나, 외부인도 이용할 수 있는지 확인하는 법

Reason:

기존 드래프트 `호텔 사우나를 고를 때 먼저 확인할 것들`은 단독 발행하기에는 정보 밀도가 약하다. 호텔 사우나의 첫 확인 순서와 외부인 이용 가능 여부 확인법을 한 편으로 묶어야 독자가 바로 써먹을 수 있다.
