# 바스타임 콘텐츠 문서

현재 바스타임은 온천 검색기 중심으로 운영합니다. 사용자에게 노출되는 온천 데이터 문장과 용어는 아래 두 문서를 기준으로 합니다.

## 현재 기준 문서

- [온천 용어 가이드](./onsen-term-guide.md): 일본 온천 용어를 한국어 서비스 화면에서 어떻게 표기할지 정합니다.
- [바스타임 판정문 작성 규칙](./onsen-judgment-copy-guide.md): 후기와 리서치 집계를 사용자용 판정문으로 바꾸는 문장 규칙을 정합니다.

## 보관 문서

예전 바스타임 콘텐츠 아카이브, 아이템 노트, 스팟 가이드, 에세이 톤 관련 문서는 [_archive/legacy-bathtime-content](./_archive/legacy-bathtime-content/)로 옮겼습니다.

해당 문서들은 과거 콘텐츠 제작 흐름을 추적하기 위한 보관 자료이며, 현재 온천 검색기 화면/카피/시드 작성의 기준으로 사용하지 않습니다.
