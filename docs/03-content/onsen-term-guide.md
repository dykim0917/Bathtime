# 온천 용어 가이드: 바스타임 온천 검색기

일본어 온천 용어를 한국어로 옮길 때 지키는 원칙과 확정 용어 목록입니다. 유후인 이후 하코네, 벳푸, 쿠로카와, 노보리베츠로 확장할 때 이 문서를 기준으로 삼습니다.

후기 집계 데이터를 사용자용 판정문으로 옮기는 문장 규칙은 [바스타임 판정문 작성 규칙](./onsen-judgment-copy-guide.md)을 따릅니다.

## 원칙

### 1. 직역하지 않는다

일본어 온천 용어를 한자 그대로 옮기면 한국인 독자는 그 뜻을 유추하기 어렵습니다. 반드시 개념이 무엇인지부터 따져보고, 그 개념을 가장 잘 설명하는 한국어를 찾습니다.

### 2. 이미 익숙한 한국어 단어에서 빌려온다

완전히 새로운 단어를 만들면 아무리 잘 만들어도 처음에는 낯섭니다. 다른 맥락에서 이미 통용되는 단어를 온천에 옮겨와 사용자가 그 감각을 그대로 가져오게 합니다.

예: `직수`는 정수기 시장의 `직수형`, 저장하지 않고 바로 흘려보내는 개념을 온천에 옮긴 말입니다.

### 3. 동음이의어를 확인한다

한자어를 그대로 옮기면 전혀 다른 뜻의 흔한 한국어 단어와 부딪힐 수 있습니다. 조어하기 전에 반드시 그 소리가 다른 뜻으로 먼저 읽히지 않는지 확인합니다.

예: `가수(加水)`는 한국어에서 거의 항상 `가수(歌手)`로 먼저 읽힙니다. 단독 명사나 배지로 쓰지 않습니다.

### 4. 짧은 조어와 정보 아이콘을 함께 쓴다

배지나 칩처럼 짧아야 하는 자리에는 조어를 쓰고, 그 옆에 정보 아이콘을 붙여 클릭하면 완전한 설명이 나오게 합니다. 반복 노출이 쌓이기 전까지는 설명을 생략하지 않습니다.

### 5. 뭉뚱그리지 않는다

겉보기에 비슷해도 실제 구조가 다르면 같은 단어를 쓰지 않습니다. 특히 예약 실수로 이어질 수 있는 용어는 구조 차이를 반드시 나눠 표기합니다.

예: `객실탕`은 `객실 안에 물리적으로 있는 탕`과 `객실 타입에만 배정된 탕`을 동시에 가리킬 수 있습니다. 이 둘은 사용자 경험이 다르므로 구분합니다.

### 6. 로마자 지역명을 화면에 노출하지 않는다

바스타임은 한국어 서비스이므로 지역명, 현/시/온천지명은 한국어 표기를 기본으로 씁니다. 데이터 내부의 `kumamoto`, `saga`, `beppu`, `kurokawa` 같은 값은 화면에 그대로 노출하지 않습니다.

지역 표기는 `권역 · 현 · 온천지` 순서로 정리합니다. 단, 같은 말이 반복될 때는 한 번만 표시합니다.

예: `규슈 · 구마모토현 · 구로카와`, `규슈 · 사가현 · 다케오`, `규슈 · 오이타현 · 벳푸`, `간토 · 가나가와현 · 하코네`, `홋카이도 · 조잔케이`

금지 예: `규슈 · kumamoto · kurokawa`, `규슈 · saga · takeo`, `규슈 · 오이타현 · beppu`, `홋카이도 · 홋카이도 · 조잔케이`

### 6-1. 플랫폼명도 한국어 UI 라벨로 노출한다

플랫폼 코드는 데이터 내부에서만 씁니다. 사용자 화면에서는 한국어 서비스에 맞는 UI 라벨로 변환합니다.

| 내부 코드 | UI 라벨 |
| --- | --- |
| `jalan` | 자란 |
| `rakuten` | 라쿠텐 |
| `google_maps` | 구글 지도 |
| `tripadvisor` | 트립어드바이저 |
| `agoda` | 아고다 |
| `yahoo_travel` | 야후 트래블 |

금지 예: `Google Maps`, `Tripadvisor`, `google_maps`, `yahoo_travel`

### 6-2. 시장별 용어 가이드를 분리한다

이 문서는 한국어 서비스용 용어 가이드입니다. `직수`처럼 한국 생활 맥락에서 빌린 조어를 다른 언어로 그대로 번역하지 않습니다.

다국어 페이지를 만들 때도 `free_flowing_source`, `room_bath`, `private_bath` 같은 내부 코드는 유지합니다. 사용자 노출 용어만 시장별 가이드에서 따로 정합니다.

예:

- 한국어: `직수`
- 영어 후보: `kakenagashi`, `free-flowing onsen`

영어권 파일럿 전에는 별도 영어 용어 가이드를 작성하고, 검색어와 사용자 이해도를 확인한 뒤 확정합니다.

### 7. 확인하지 못한 항목을 서비스 실패처럼 보이게 쓰지 않는다

`확인 필요`, `조건 확인`, `확인 중`을 단독으로 쓰면 사용자는 “그럼 무엇을 확인해준 서비스인가?”라고 느낄 수 있습니다. 모르는 것을 숨기지는 않되, 아는 것과 모르는 것의 경계를 문장 안에서 분리합니다.

좋은 예:

- `예약 전 확인`: 예약 직전 확인해야 하는 변동 조건에 씁니다.
- `중심 항목 아님`: 해당 숙소의 핵심 판단 축이 아닐 때 씁니다.
- `이용 경험 기준`: 공식 확정이 아니라 이용 경험 집계로 판단했을 때 씁니다.
- `온천 운용 확인됨`: 무엇이 확인됐는지 함께 적습니다.

피해야 할 예:

- `확인 필요`
- `조건 확인`
- `확인 중`
- `언급 있음`

### 8. 문장은 접합부까지 검수한다

템플릿 문구를 이어 붙일 때 조사와 마침표가 깨지면 전체 데이터의 신뢰도가 떨어집니다. 짧은 문장을 여러 개로 나눠 자연스럽게 연결합니다.

좋은 예: `직수 방식으로 정리했습니다. 객실 노천탕 중심입니다. 계절에 따라 벌레나 냉감을 함께 확인하세요.`

나쁜 예: `객실 노천탕 중심입니다, 계절에 따라 벌레나 냉감 확인을 권장합니다 조건을 함께 봅니다`

## 확정 용어

| 일본어/직역 | 바스타임 용어 | 사용 규칙 |
| --- | --- | --- |
| 源泉100%かけ流し | 순수직수 | 공식 표기로 원천 100% 직수이며, 물을 더하지도 데우지도 않는다는 점이 확인될 때만 씁니다. |
| 源泉かけ流し, かけ流し | 직수 | 흘려보내는 방식이 확인될 때 씁니다. 가수·가온 여부는 조건 라인으로 따로 풉니다. |
| 循環ろ過, 循環式, 순환식 | 순환식 온천 | 온천수를 순환·여과해 다시 쓰는 방식입니다. 쉬운 말을 기본값으로 두고 필요할 때 괄호에 순환식을 병기합니다. |
| 加水, 가수 | 물을 섞어 식힘 | 서술형으로만 사용합니다. 단독 명사나 배지로 쓰지 않습니다. |
| 加温, 가온 | 데워서 온도 조정 | 서술형 또는 조건 라인으로만 사용합니다. 단독 배지로 쓰지 않습니다. |
| 消毒, 소독 | 소독 표기 있음 | 상세 사실 필드나 조건 라인에만 씁니다. 위생·안전 평가처럼 쓰지 않습니다. |
| 物性, 물성 | 물의 감촉 / 수질 | 필터 축에는 물의 감촉, 공식 사실 필드에는 수질을 씁니다. |
| 内湯, 내탕 | 실내탕 | 노천탕과 짝을 맞춰 씁니다. |
| 貸切風呂, 대여탕 | 대절탕 | 대절버스처럼 이미 익숙한 단어로 통일합니다. |
| 客室風呂, 객실탕 | 객실 내 프라이빗탕 / 객실 전용탕 | 물리적으로 객실 안에 있으면 객실 내 프라이빗탕, 특정 객실 타입에 배정된 구조라면 객실 전용탕으로 구분합니다. |
| 家族風呂, 가족탕 | 대절탕 / 가족 단위 대절탕 | 일본 숙소의 `家族風呂`는 한국 목욕장 가족탕과 다르게 운영될 수 있습니다. 기본 표기는 대절탕으로 두고, 가족 단위 이용이 핵심일 때만 설명 문장에서 풉니다. |
| 大浴場, 대욕장 | 대욕장 | 공용으로 쓰는 큰 온천탕입니다. 객실 내 프라이빗탕, 대절탕과 합치지 않습니다. |
| 共同浴場, 공용탕 | 공용 온천 / 대욕장 | `공용탕`은 화면 용어로 쓰지 않습니다. 숙소 안의 큰 탕이면 대욕장, 지역 시설이나 공동 이용 성격이면 공용 온천으로 씁니다. |

### 대상 유형과 이용 방식

대상 자체와 이용 가능 방식을 한 용어에 섞지 않습니다. 숙소와 분리된 시설의 화면 유형은 `온천시설`로 통일하고, `당일온천`은 검색 동의어로만 유지합니다.

| 구분 | 화면 용어 | 사용 규칙 |
| --- | --- | --- |
| 대상 유형 | 숙소 / 온천시설 | 결과 필터와 카드 유형에 씁니다. |
| 이용 방식 | 숙박 / 당일 이용 | 탐색 조건처럼 사용자의 행동을 나눌 때 씁니다. |
| 운영 사실 | 당일 입욕 가능 | 상세 페이지에서 비투숙객 이용 가능 여부를 정확히 밝힐 때 씁니다. |
| 검색 동의어 | 당일온천 / 당일치기 온천 | 검색어 매칭과 SEO에는 유지하되 유형 배지로 쓰지 않습니다. |

## 온천수 방식 배지

온천수 방식 배지는 획득하는 정보입니다. 공식 표기나 그에 준하는 출처로 확인된 경우에만 부여합니다. 이용 경험에서 직수처럼 보인다는 표현이 반복되더라도, 후기만으로 방식 배지를 부여하지 않습니다.

배지는 등급 이름을 길게 만들지 않습니다. 사용자는 `직수인가`, `무엇을 조정했는가`, `순환식인가`를 빠르게 이해해야 합니다.

| 배지 | 부여 조건 | 조건 라인 |
| --- | --- | --- |
| 순수직수 | `源泉100%かけ流し` 또는 원천 100%, 무가수, 무가온, 무순환이 공식 정보로 확인됨 | 없음 |
| 직수 | `源泉かけ流し` 또는 `かけ流し`가 공식 정보로 확인됨 | 가수·가온·원천 여부를 함께 표시합니다. |
| 순환식 온천 | `循環ろ過`, `循環式`이 공식 정보로 확인됨 | 소독, 가온 등 추가 조건이 있으면 함께 표시합니다. |
| 무배지 | 위 방식 중 어느 것도 공식 정보로 확인하지 못함 | 상세 페이지에서 확인 경계를 문장으로 풉니다. |

조건 라인 예:

- `물을 더하지도, 데우지도 않고 원천 그대로 흘려보냅니다.`
- `직수 방식입니다. 가온 여부는 예약 전 확인하세요.`
- `직수 방식입니다. 겨울철 가온이 있습니다.`
- `직수 방식입니다. 원천 여부는 예약 전 확인하세요.`
- `온천수를 순환·여과해 사용하는 방식입니다.`

무배지는 낮은 등급이 아니라 방식 배지를 줄 근거가 아직 없다는 뜻입니다. 상세 페이지에서는 데이터 상태에 따라 아래처럼 나눠 씁니다.

| 데이터 상태 | 상세 문구 |
| --- | --- |
| 온천수 사용은 확인됨, 방식 미확인 | 온천수 사용은 확인했지만, 직수인지 순환식인지는 예약 전 확인이 필요합니다. |
| 온천수 사용 여부 자체가 미확인 | 온천수 사용 여부를 공식 정보에서 확인하지 못했습니다. |
| 이름에만 온천이 있고 실제 물 근거 없음 | 온천수 사용 근거를 아직 확인하지 못했습니다. |

금지:

- `100% 원천 직수`, `완전직수`, `진짜 직수`처럼 수식어를 쌓은 배지
- `천연온천`을 방식 배지나 핵심 필터로 쓰는 것
- 근거 필드 없는 직수 배지 렌더링
- 무배지 숙소를 `수돗물`로 단정하는 문장

지역 재고 카운터에는 우선 `순수직수`만 최상위 재고로 셉니다. `직수`는 방식 확인 수치로 별도 표기할 수 있지만, 가수·가온 조건을 함께 노출할 수 있을 때만 사용합니다.

## 물의 감촉 필터

물의 감촉은 효능을 말하는 축이 아닙니다. 공식 수질과 이용 경험의 감각 표현을 연결해 사용자가 물의 성격을 가늠하게 하는 필터입니다.

필터 라벨은 판정 카운트의 단위와 맞춥니다. 사용자가 `미끌미끌`을 누르면 판정문도 물의 미끌거림·매끈함 언급 수를 보여줘야 합니다.

| 필터 칩 | 연결되는 수질 | 설명 | 판정 카운트 |
| --- | --- | --- | --- |
| 미끌미끌 | 탄산수소염천, 알칼리성 단순온천(pH 8.5 이상) | 물이 미끌미끌한, 일본에서 미인탕으로 불리는 계열입니다. | 미끌거림, 매끈함 언급 |
| 소금탕 | 염화물천, 황산염천 | 염분 계열의 온천입니다. 탕에서 나온 뒤 따뜻함이나 촉촉함 언급을 함께 봅니다. | 나온 뒤 따뜻함, 촉촉함 언급 |
| 유황탕 | 유황천 | 유황 냄새가 진한, 온천 실감이 강한 계열입니다. | 유황 냄새, 온천 실감 언급 |
| 탄산온천 | 이산화탄소천 | 기포가 피부에 붙는 탄산 계열입니다. | 기포, 탄산 언급 |

감촉 필터는 카운트 없는 감각 문장으로 노출하지 않습니다. 예:

`이용 경험 234건 중 141건이 물의 미끌거림·매끈함을 언급합니다. 건조감 언급 3건을 함께 확인했습니다.`

금지:

- `피부가 좋아진다`, `미백`, `아토피에 좋다` 같은 효능 단정
- `비단탕`, `톡톡탕`처럼 새로 만든 감각 명사
- 염화물천을 `해수탕`으로 부르는 것
- 카운트 없는 감촉 서술

## 물의 색 필터

물의 색은 물의 감촉과 별도 축으로 둡니다. 색은 이용 경험만으로 단정하지 않고, 공식 공시·공식 사진·시설 안내에서 확인된 경우에만 필터로 노출합니다. 이용 경험의 색 언급은 보조 카운트로만 씁니다.

| 필터 칩 | 연결되는 수질/표기 | 설명 | 검증 신호 |
| --- | --- | --- | --- |
| 백탁 | 백탁, 유백색, 니고리유, 유황천 계열 공식 표기 또는 공식 사진 | 물이 우유처럼 뽀얗게 흐려지는 니고리유 계열입니다. | 공식 확인 + 백탁·우유빛 언급 카운트 |
| 갈색빛 | 함철천, 철분, 적갈색, 갈색 공식 표기 또는 공식 사진 | 철분으로 물이 갈색·적갈색으로 물드는 계열입니다. | 공식 확인 + 갈색·적갈색 언급 카운트 |
| 투명 | 그 외 또는 색 강조 없음 | 기본값이므로 필터 칩으로 팔지 않고 상세 사실 필드에만 표기합니다. | 공식 수질/사진 확인 시 상세 표기 |

색 필터는 사진만 보고 과장하지 않습니다. 공식 사진이 조명, 탕 바닥 색, 계절 탁도에 영향을 받을 수 있으므로 가능하면 공식 텍스트 표기와 함께 확인합니다.

금지:

- `우유탕`, `밀크탕`처럼 실제 성분을 오해하게 하는 발명 명사
- 공식 근거 없이 후기의 색 표현만으로 색 필터를 부여하는 것
- 투명한 물을 우월한 속성처럼 마케팅하는 것

## 수질 표기

수질은 상세 페이지의 사실 필드로 남깁니다. 필터는 물의 감촉과 물의 색처럼 사용자가 실제 선택에 쓰는 축으로만 파생하고, 공식 수질명은 상세에서 정확히 보여줍니다.

| 수질 | 필터 연결 | 상세 한 줄 설명 |
| --- | --- | --- |
| 단순온천 | 없음 | 성분이 옅어 자극이 적은 온천입니다. |
| 알칼리성 단순온천 | 미끌미끌 | 성분은 옅지만 물이 미끌미끌한 알칼리성 온천입니다. |
| 탄산수소염천 | 미끌미끌 | 일본에서 미인탕으로 불리는 계열입니다. |
| 염화물천 | 소금탕 | 염분 계열의 온천입니다. 탕에서 나온 뒤 따뜻함 언급을 함께 봅니다. |
| 황산염천 | 소금탕 | 보습 계열로 분류되는 황산염천입니다. 피부 당김 언급은 이용 경험 카운트로만 다룹니다. |
| 유황천 | 유황탕 | 유황 냄새가 진한 온천입니다. 건조·자극 언급이 있으면 함께 표시합니다. |
| 이산화탄소천 | 탄산온천 | 기포가 피부에 붙는 탄산천 계열입니다. |
| 함철천 | 없음 | 철분으로 물이 갈색·적갈색으로 보일 수 있는 온천입니다. |
| 산성천 | 주의 라벨 | 자극이 강한 산성천입니다. 민감한 피부는 짧게 이용하세요. |
| 방사능천 | 사실 표기만 | 방사능천 또는 라돈천으로 분류되는 온천입니다. 효능 서사는 쓰지 않습니다. |
| 함요오드천 등 기타 | 없음 | 공식 수질명만 최소 표기합니다. |

산성천은 추천 필터가 아니라 주의 라벨입니다. 방사능천은 요양, 호르미시스, 치료 효과 같은 서사를 붙이지 않습니다.

바스타임의 판정문과 상세 화면에서는 `후기`보다 `이용 경험`을 기본 표현으로 씁니다.

## 배지에 쓸 때 형식

`순수직수 ⓘ`

설명: 물을 더하지도, 데우지도 않고 원천 그대로 흘려보내는 방식입니다. 공식 정보로 확인된 경우에만 붙입니다.

`직수 ⓘ`

설명: 온천수를 흘려보내는 방식입니다. 가수·가온 여부는 조건 라인으로 함께 확인합니다.

`순환식 온천 ⓘ`

설명: 온천수를 순환·여과해 다시 쓰는 방식입니다. 소독, 가온 같은 추가 조건은 상세 문장으로 함께 봅니다.
