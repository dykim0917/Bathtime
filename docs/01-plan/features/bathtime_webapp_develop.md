Bath Time 웹 → 앱 전환 전략 문서
Web-to-App Handoff Strategy
1. 문서 목적

이 문서는 Bath Time의 웹과 앱 역할을 분리하고,
웹에서 사용자가 콘텐츠를 탐색한 뒤 앱으로 자연스럽게 이동하도록 유도하는 구조를 정의한다.

핵심 방향은 다음과 같다.

웹은 아카이브 탐색 중심
앱은 저장, 실행, 보관 중심
웹에서는 의식 / 루틴 기능을 전면 탭으로 두지 않고,
콘텐츠 하단 CTA를 통해 앱으로 연결하는 방식을 사용한다.

즉, 루틴은 웹에서 “읽는 정보”로는 존재할 수 있지만,
실행 경험은 앱에서 완성되도록 설계한다.

4. 웹에서 루틴을 다루는 방식
4.1 최상위 탭이 아니라 CTA로 다룬다

웹에서는 루틴을 독립 메뉴로 전면 배치하지 않고,
콘텐츠와 연결된 “다음 행동” 으로 배치한다.

예:

스팟 콘텐츠를 읽는다
아이템 콘텐츠를 읽는다
홈스파 콘텐츠를 읽는다
하단에서 “앱에서 이 의식 따라 해보기” CTA를 본다
앱 설치/열기 유도

루틴명

간단한 단계 2~3개

실행 기능은 앱으로 보낸다.

- 준비물: 족욕볼, 수건
- 이런 날 좋아요: 몸이 무겁고 차분해지고 싶을 때

5. 웹 → 앱 CTA 전략
5.1 CTA 목적

웹 CTA의 목적은 단순 앱 설치 유도가 아니다.

진짜 목적
“앱이 왜 필요한지”를 명확히 납득시키는 것
웹은 정보 탐색에 좋고,
앱은 저장/실행에 더 적합하다는 점을 전달하는 것

즉, 앱 CTA는 기능 광고가 아니라 행동 전환 장치다.

5.2 CTA를 두는 위치
1. 콘텐츠 상세 하단

가장 기본적인 위치

이 의식 앱에서 따라 해보기
저장한 뒤 나중에 다시 꺼내볼 수 있어요.
[앱에서 열기]
2. 구조화 정보 박스 아래

콘텐츠를 이해한 직후 실행 욕구가 생길 수 있는 지점

3. 관련 콘텐츠 섹션 위/아래

비슷한 콘텐츠를 더 보기 전에 “실행하기”를 유도

4. Saved 빈 상태 화면

웹에서 저장함을 보다가 앱의 필요성을 느끼게 만들 수 있음

저장한 바스타임을 앱에서 더 편하게 관리할 수 있어요.
[앱에서 보기]
5. 루틴 미리보기 카드 내부

웹에서 루틴을 전면 제공하지 않고, 앱 전환을 위한 맛보기로 활용

B. 저장형 CTA

앱에서는 나만의 바스타임을 보관할 수 있어요

7. CTA 노출 원칙
7.1 과하게 강요하지 않는다

웹은 콘텐츠 경험이 먼저다.
앱 설치 CTA는 콘텐츠를 방해하면 안 된다.

원칙
팝업 남발 금지
첫 화면 진입 즉시 강제 설치 유도 금지
콘텐츠를 충분히 읽은 뒤 CTA 노출
앱이 필요한 이유를 먼저 설명
7.2 웹에서의 가치도 충분해야 한다

웹이 앱 유도용 미끼처럼 느껴지면 안 된다.

즉:

웹 콘텐츠만으로도 유용해야 하고
앱은 그 다음 단계의 도구여야 한다
정리
웹 = 가치 제공
앱 = 실행 효율 강화
7.3 CTA는 기능이 아니라 맥락으로 설명한다

나쁜 예:

앱 다운로드

좋은 예:

이 의식을 앱에서 따라 해보기
앱에서 저장하고 나중에 다시 보기
앱에서 내 바스타임으로 보관하기
8. 앱 CTA용 추천 카피
8.1 기본형
앱에서 이 의식 따라 해보기
앱에서 루틴으로 저장하기
앱에서 나중에 다시 보기
앱에서 내 바스타임으로 보관하기
8.2 설명형
이 콘텐츠를 앱에 저장하면,
나중에 다시 꺼내보고 관련 루틴까지 함께 볼 수 있어요.

앱에서는 저장한 바스타임을 한곳에 모아볼 수 있어요.

앱에서는 이 의식을 바로 실행할 수 있어요.
8.3 스팟형
이 장소를 저장해두고,
앱에서 비슷한 바스타임 장소를 더 찾아보세요.
8.4 루틴형
이 의식은 앱에서 더 편하게 따라 할 수 있어요.
순서대로 저장하고 실행해보세요.

12. P0 완료 기준

다음 조건을 만족하면 웹 → 앱 전환 구조가 P0 완료된 것으로 본다.

웹 최상위 IA에서 Routines가 제거되었다
콘텐츠 상세에서 앱 CTA가 노출된다
루틴 관련 정보는 웹에서 미리보기 수준으로만 보인다
앱에서 할 수 있는 행동이 명확히 설명된다
CTA 클릭 이벤트가 측정된다
사용자가 웹에서 콘텐츠를 읽고 앱 필요성을 이해할 수 있다
13. 한 줄 요약

웹은 바스타임을 발견하는 곳, 앱은 바스타임을 저장하고 실행하는 곳이다.
따라서 웹에서는 루틴을 전면 탭으로 두지 않고, 콘텐츠 하단 CTA를 통해 앱으로 자연스럽게 연결한다.
