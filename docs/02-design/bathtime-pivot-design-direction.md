# 바스타임 저장·아카이빙 피벗 디자인 방향

사용자 지정: 2026-09-22. 이후 피벗 작업에서 유지할 디자인·언어·화면 범위입니다.

## 사용자 결정

- 오늘의집·화해처럼 **깔끔하고 청량한 인상**을 지향합니다.
- 토스처럼 **짧고 이해하기 쉬운 한국어**를 씁니다.
- **휴대폰을 우선 설계하고 태블릿도 지원합니다.** 2026-09-22 추가 결정으로 기존 휴대폰 전용 범위를 확장합니다. 데스크톱 전용 구성은 만들지 않습니다.
- 보관함은 **장소·제품 중심**입니다. 그 안에서 저장한 게시물을 확인합니다.

## 시각 방향

흰 바탕에 사진과 제목을 먼저 보여주고, 민트·시안 계열 색으로 선택 상태와 주요 행동을 표시합니다. 연한 회색으로 영역을 나누고, 읽는 데 필요한 여백을 확보합니다. 기본 서체는 한국어 산세리프입니다. 기존의 종이색 배경, 황동빛 강조, 명조 헤드라인은 이번 피벗에 적용하지 않습니다.

사진과 정보의 위계, 밝은 색감, 탐색의 명료함을 참고합니다. 다른 서비스의 로고·아이콘·문구를 그대로 사용하지 않습니다.

현재 샘플의 색상은 수정 가능한 첫 적용값입니다.

| 용도 | 값 |
| --- | --- |
| 화면·카드 | `#FFFFFF` |
| 보조 배경 | `#F5F8FA` |
| 주요 글자 | `#20282D` |
| 보조 글자 | `#63717A` |
| 주요 버튼·강조 글자 | `#007F89` |
| 밝은 포인트 | `#26C6D0` |
| 선택 배경 | `#E9FAFA` |
| 구분선 | `#E8EEF1` |

## 휴대폰·태블릿 구성

기본 폰트는 **Pretendard**로 지정합니다(2026-09-22 사용자 요청). 이름만 선언하지 않고 실제 웹폰트를 로드해야 합니다. 현재 샘플은 공식 배포 경로의 v1.3.9 가변 서브셋 CSS를 연결하고 `Pretendard Variable`을 우선 사용합니다.

- 휴대폰 확인 기준: 360–430 CSS px 폭. 태블릿은 세로·가로 방향과 분할 화면에서 실제 사용 가능한 폭을 확인합니다. 같은 정보 순서와 탐색 흐름을 유지합니다.
- 태블릿은 440px 휴대폰 프레임에 고정하지 않습니다. 카드의 가독성과 터치 크기를 유지하면서 화면 폭에 맞춰 열 수·여백을 조정합니다. PC 미리보기는 휴대폰·태블릿 화면 검증용이며 별도 PC 제품 화면은 만들지 않습니다.
- 목록: 사진 → 지역·종류 → 이름 → 핵심 특징·이용 조건. 설명 문장은 상세에 둡니다.
- 첫 시안은 모바일 2열 카드입니다. 열 수·세부 간격은 사용자 피드백으로 조정할 수 있습니다.
- 상세는 휴대폰에서 전체 화면으로 열고, 태블릿에서는 본문이 지나치게 넓어지지 않도록 읽기 폭을 제한합니다. 상단 닫기와 주요 행동을 유지합니다.
- 주요 터치 영역은 44px 이상을 기본으로 합니다. 작은 글자·긴 단어·가로 넘침을 확인합니다.
- 아직 동작하지 않는 탐색 메뉴나 저장 버튼을 장식으로 추가하지 않습니다.

## 언어

- 제목은 명확하게: `보관함`, `이용 정보`, `저장한 게시물`.
- 버튼은 실행 결과를 예측할 수 있게: `지도에서 찾기`, `Instagram에서 보기`, `전체 보기`.
- 설명은 자연스러운 해요체, 항목 값은 짧은 명사·숫자로 씁니다.
- 의미 없는 안내와 반복 문장을 줄입니다. 수집·분석 과정은 이용에 꼭 필요할 때만 설명합니다.
- 남성·여성 전용, 온탕 유무, 과거 요금·시간 같은 중요한 조건은 줄이지 않습니다.
- 작성자의 경험을 앱의 추천이나 공식 사실로 바꾸지 않습니다. 공식 안내, 게시물 소개, 확인일을 구분합니다.
