# 바스타임 디자인 시스템 V2 후보

상태: 메인 시안 A/B 검토용 후보 계약

기존 `DESIGN.md`는 시안 확정 전까지 운영 기준으로 유지한다. 이 문서는 새 메인과 이후 공통 UI 이관을 위한 압축된 디자인 계약이다.

## 1. Atmosphere

### Quiet Onsen Atlas

바스타임은 일본 온천의 장소성과 이용 조건을 함께 정리하는 발견형 판정 아카이브다. 메인은 온천에 가고 싶은 마음을 만들고, 결과는 후보를 좁히며, 상세는 판정으로 선택에 확신을 준다. 실제 목욕 장면과 여행의 감정이 첫 화면의 무게를 맡고, 검색은 모든 화면의 공통 헤더 도구로 유지한다. 얇은 선과 정확한 숫자, 낮은 목소리의 판정문이 신뢰를 만든다.

호텔 스파의 금색 고급감, 장식적인 일본풍, 건강관리 앱의 차가운 청결함은 사용하지 않는다. 방법론 페이지의 편집 감각을 브랜드 상위 언어로 삼고 검색·필터·상세에서는 더 조밀한 도구형 문법으로 번역한다.

- Confirmed: Primary
- Information: Mineral
- Attention: Iron
- Neutral: Muted + Surface Soft
- Disabled: Muted 52% + Surface Soft

큰 면적은 Canvas, Surface, 실제 사진이 담당한다. Primary, Mineral, Iron은 한 화면에서 각각 하나의 의미로만 사용한다.

대비 기준은 일반 텍스트 4.5:1, 큰 텍스트와 UI 경계 3:1 이상이다.

## 3. Typography

### Font Roles

- Editorial: `"Noto Serif KR", "AppleMyungjo", "Batang", serif`
- Sans: `Pretendard, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- Data: Sans와 같은 Pretendard 스택 + `font-variant-numeric: tabular-nums`

명조는 메인 H1, 방법론 제목, 장소명처럼 브랜드 인상을 만드는 곳에만 사용한다. 검색, 필터, 판정, 본문, 폼과 숫자는 Sans를 사용한다. 숫자 정렬이 필요한 표와 통계에서는 별도 모노스페이스 글꼴 대신 `tabular-nums`만 적용한다.

## 5. Components

### Shell

1. Discovery: 메인, 공통 검색 헤더와 목욕하는 순간 중심 첫 화면
2. Utility: 결과·상세·여권·탐색, 밝은 고정 헤더
3. Minimal: 로그인·법적 문서, 로고와 핵심 행동만 표시

- Discovery 계정 액션은 44px 원형 영역 안의 사용자 아이콘만 노출하고 `aria-label`과 tooltip으로 의미를 제공
- 모바일 온천 헤더는 검색 입력을 숨기고 44px 검색 아이콘으로 기존 전체화면 검색 시트를 실행

### Search

- Desktop height 64px, mobile 52px
- 메인·결과·상세 헤더에서 같은 검색 위치와 8px geometry를 사용
- 메인도 결과·상세와 같은 `OnsenSearchForm` header variant를 사용해 자동완성, 추천 지역, 최근 검색어, 모바일 검색 시트를 공유
- 메인 히어로에는 별도의 검색 입력을 중복 배치하지 않음
- 데스크톱은 헤더 검색창, 모바일은 아이콘으로 여는 검색 시트를 사용
- 데스크톱 헤더 검색 팝오버는 입력 폭과 분리해 검색창 중심의 최대 760px 읽기 폭을 사용
- 추천 지역은 메인과 같은 지역 사진을 `64×48px` 썸네일로 표시하고, 입력 중 자동완성은 위치 아이콘을 유지
- 결과 헤더 검색은 radius 8px
- 입력, 검색 버튼, 초기화, 자동완성 그룹의 hover, focus, disabled를 모두 정의
- 모바일 검색 시트의 터치 대상은 최소 44px

### Desire Sections

- 홈의 첫 발견 단위는 지역이나 숙소가 아니라 사용자가 원하는 목욕의 순간
- 상위 설명 제목과 축약 탭을 두지 않고 감정 문장 자체를 각 섹션의 제목으로 사용
- 첫 공개 범위는 `아무도 없는 탕`, `둘만 쓰는 객실탕`, `눈이나 숲` 세 장면
- 감정 문장 바로 아래에 실제 결과로 번역되는 조건을 굵게 표시하고 관련 후보 카드 세 개를 연결
- 세 섹션은 같은 카드 복제처럼 보이지 않도록 균등 3열, 대표 장면과 후보 목록을 결합한 7:5 편집형, 풍경 중심 3열로 리듬을 달리함
- `둘만 쓰는 객실탕`은 대표 후보의 사진과 판정문을 한 장면으로 크게 보여주고, 나머지 두 후보는 128px 사진과 텍스트를 결합한 얇은 목록으로 배치
- 편집형 대표 사진은 16:9, 보조 목록 사진은 정사각형을 사용하며 카드 밖 별도 장식은 추가하지 않음
- 모바일은 각 섹션의 후보 카드를 가로 스냅으로 탐색
- `아무도 없는 탕`처럼 보장할 수 없는 바람은 결과에서 대절탕·객실 내 프라이빗탕처럼 확인 가능한 조건으로 번역

### Discovery Hero Carousel

- 메인 히어로는 같은 360px/320px frame과 52px scene controls 안에서 다섯 장면을 수동 비교
- 모든 슬라이드는 실제 이미지 위에 감정 카피를 직접 배치하며 텍스트 카드나 split hero를 사용하지 않음
- 따뜻한 실내, 눈 내리는 탕, 비 오는 숲, 온천마을, 원천 풍경을 서로 다른 이미지 초점과 좌우 정렬로 구성
- 자동 재생은 사용하지 않고 이전·다음 화살표, 원형 점 controls, 키보드 방향키, 모바일 스와이프를 제공
- 화살표는 무선 반투명 원형으로 간격을 벌리고, 점 controls는 히어로 하단에 겹쳐 조작부의 존재감을 낮춤
- 슬라이드 전환은 opacity만 사용하며 hero height와 뒤 섹션 위치를 바꾸지 않음

### Home Passport Band

- 로그인 사용자에게만 메인 히어로 바로 아래에서 표시
- 홍보 카드가 아니라 전폭 개인 기록 밴드로 구성하고, 수직 구분선과 실제 여권 데이터로 위계를 만듦
- 기록이 있으면 다녀온 곳, 남긴 기록, 자주 고른 감촉, 최근 기록을 표시하고 온천여권으로 연결
- 기록이 없으면 첫 기록을 남길 온천 탐색으로 연결
- 로딩과 오류는 같은 밴드 geometry 안에서 처리하고, 로그아웃 상태에서는 빈 자리 없이 밴드 전체를 숨김
- 모바일은 통계 세 칸을 유지하되 소개, 최근 기록, CTA를 세로로 배치

### Buttons

- Default radius 8px
- Icon-only button은 familiar symbol + tooltip 또는 aria-label 사용
- 주요 CTA 높이 48px, 보조 CTA 높이 44px
- Hero search만 pill 허용

### Cards

- 개별 반복 항목에만 사용
- radius 8px 이하
- 기본 깊이는 border와 면 차이
- 이미지 카드 hover는 이미지 transform만 사용
- 섹션 전체를 카드로 감싸지 않음

### Result Item

- Image
- Entity label + location
- Name
- One-sentence verdict
- Two decisive facts
- Evidence count

배지는 한 줄에 최대 두 종류만 표시한다. 숙소와 당일온천은 정보 구조는 공유하되 서로 다른 사실 라벨을 사용한다.

### Results Workspace

- 별도 히어로 없이 공통 검색 헤더 바로 아래에서 결과 수와 현재 조건을 먼저 표시
- 결과 제목 아래에 재고 설명문을 반복하지 않고 제목·수·정렬 다음으로 바로 필터와 목록을 연결
- 데스크톱은 `280px` 고정 필터 레일과 한 열 가로형 결과 목록으로 구성
- 필터 순서는 유형, 목욕 구성, 온천수, 감촉·색, 공식 편의 조건
- 지역과 온천지는 필터에 중복 노출하지 않고 공통 검색으로만 진입
- 현재 선택 조건은 결과 제목 아래에서 제거 가능한 칩으로 반복하고 전체 초기화를 함께 제공
- 결과 카드는 사진, 장소·유형, 이름·온천수 배지, 한 문장 판정, 결정 사실 두 개, 후기 근거와 바스타임 후기 수 순서로 읽힘
- 순수직수·직수·순환식 온천은 선이나 배경 없는 월계수와 금·은·동 색으로 단계감을 주되 색상은 해당 인증 표식 안에서만 사용
- 외부 후기 분석 수와 바스타임 자체 후기 수는 서로 다른 데이터로 분리하고, 자체 후기는 화면에서 코멘트 아이콘과 건수만 표시
- 카드 오른쪽의 결정 사실 영역은 본문과 선으로만 구분하며 별도 중첩 카드로 만들지 않음
- 정렬은 결과 제어 바에서 제공하고, 한 페이지의 결과는 24개를 기준으로 나눔
- 모바일은 결과 수와 필터·정렬 행동을 먼저 두고 필터를 전면 시트로 열며, 카드는 사진 아래 판정과 사실을 세로로 배치
- 현재 사진 준비 상태가 아니라 아고다 제휴 이미지가 채워진 완성 상태의 카드 비율을 기준으로 설계
- 결과 제목은 Sans로 통일하고 수치만 과도하게 강조하지 않음
- 카드 이미지는 왼쪽 외곽선까지 여백 없이 채우고, 내부 카피와 결정 사실에만 패딩을 적용
- 넓은 데스크톱에서는 결과 목록 오른쪽에 실제 지도를 기본 표시하며 지도 닫기 시 목록이 전체 폭으로 확장
- 지도 표시 중에는 카드가 사진·판정 본문과 하단 결정 사실의 조밀한 구조로 전환
- 태블릿과 모바일 지도는 별도 전면 시트로 열고 닫을 때 원래 조작 위치로 초점을 돌려줌
- 지도 지명은 한국어를 우선하고, 한국어 데이터가 없을 때 영어와 현지명 순으로 대체

### Evidence Strip

- 카드가 아닌 full-width band
- 읽은 후기, 확인한 온천 숙소, 당일온천, 방법론 링크
- 숫자는 Data 크기와 `tabular-nums`, 설명은 Sans
- 홈에서는 발견 섹션 뒤에 배치해 감정적 탐색을 숫자로 방해하지 않음

### Method Band

- 마지막 확인 기준은 전폭 실제 이미지 위에 판정 방법 카피를 배치
- 이미지는 모든 뷰포트에서 밴드 프레임 전체를 `cover`하고, 원본 비율 때문에 배경 여백을 만들지 않음
- 모바일은 카피를 하단 정렬하되 이미지와 오버레이가 같은 프레임 전체를 채움

### Overlay

- Surface + 8px radius
- lifted shadow는 modal, popover, search sheet에만 사용
- backdrop scrim은 Ink 34%

## 6. Motion

- Fast 100ms
- Base 160ms
- Reveal 280ms
- Ease out `cubic-bezier(0.22, 1, 0.36, 1)`

애니메이션 속성은 `transform`, `opacity`, `filter`만 사용한다.

- Region image hover: scale 1.025
- Button press: scale 0.98
- Reveal: opacity 0 to 1, translateY 12px to 0
- Search sheet: opacity + translateY

`prefers-reduced-motion`에서는 transform을 제거하고 콘텐츠를 기본 표시한다.

## 7. Depth

기본 전략은 tonal surface + 1px border다.

- Level 0: Canvas, shadow 없음
- Level 1: Surface, border만 사용
- Level 2: Overlay, `0 18px 48px rgba(24, 37, 34, 0.16)`

카드 hover에서 shadow를 키우지 않는다. 사진과 타이포그래피가 시각적 위계를 만든다.

## Image Assumption

아고다 어필리에이트 승인 후 숙소·시설 사진이 제공되는 완성 상태를 기준으로 설계한다. 시안에서는 기존 지역 사진을 geometry 검증용 프록시로 사용한다.

`사진 준비 중`은 임시 운영 상태이며, 메인·결과·상세의 미디어 비중을 줄이는 근거로 사용하지 않는다. 실제 제휴 이미지 적용 후 crop, focal point, 저작권 표기, 로딩 성능을 별도로 QA한다.

## Do And Do Not

### Do

- 실제 목욕 장면과 여행의 감정을 메인 첫 화면의 핵심 신호로 사용
- 검색은 공통 헤더에서 항상 접근 가능하게 유지
- 홈의 감정 문장을 결과 페이지에서 확인 가능한 조건으로 번역
- 실제 장소 사진은 순간 선택과 지역 탐색에 충분히 사용
- 숫자와 출처 상태를 조용하게 반복
- 화면마다 같은 shell, type, status vocabulary 사용
- 검색 화면은 조밀하고 반복 사용하기 쉽게 구성

### Do Not

- 베이지와 금색으로 고급 스파 분위기 만들기
- 모든 섹션을 둥근 카드로 만들기
- 사진 위에 많은 pill 겹치기
- 배경, 경계선, 그림자 애니메이션
- 페이지별 raw 색상과 임의 반경 추가
