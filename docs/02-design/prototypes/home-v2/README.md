## 공통 전제

- 아고다 어필리에이트 승인 후 숙소·시설 이미지가 제공되는 완성 상태를 기준으로 설계했다.
- 현재 지역 사진은 제휴 이미지 geometry를 검증하기 위한 프록시다.

- 통계는 현재 서비스의 실제 노출 수치를 사용했다.

## A. Desire Atlas

온천에 가고 싶은 마음을 만들고, 원하는 목욕의 순간을 실제 검색 조건으로 번역하는 발견형 메인이다. 검색은 결과·상세와 같은 공통 헤더 도구로 유지한다.

### 강점

- 메인 첫 화면에서 온천이 여행의 목적이 되는 감정을 전달한다.
- 따뜻한 실내, 설경, 비 오는 숲, 온천마을, 원천 풍경의 다섯 히어로를 한 화면에서 비교할 수 있다.
- 지역이나 숙소를 모르는 사용자도 원하는 목욕의 장면부터 시작할 수 있다.
- 세 개의 감정 문장이 대절탕, 객실 내 프라이빗탕, 노천탕 같은 실제 조건과 독립된 후보 섹션으로 연결된다.
- 감성 hero carousel, 세 개의 desire section, 지역 mosaic, 온천수 index가 서로 다른 layout family를 사용한다.
- 제휴 이미지가 좋아질수록 화면의 가치가 함께 커진다.

### 트레이드오프

- 순간 선택에 필요한 풍경·혼잡·대욕장 신호는 결과 페이지 필터와 연결할 데이터 규칙이 필요하다.
- 감정 문장이 객관적 사실처럼 보이지 않도록 결과에서 적용 조건을 명확히 공개해야 한다.

## B. Evidence Index

조건 선택과 최신 판정을 먼저 보여주는 도구형 메인이다.

### 강점

- 사용자가 무엇을 검색할 수 있는지 바로 이해할 수 있다.
- 숙소와 당일온천, 탕 구성, 온천수 필터의 확장성이 잘 보인다.
- 최근 판정 업데이트를 조밀하게 노출할 수 있다.
- 검색 결과 페이지와의 연결이 직접적이다.

### 트레이드오프

- A안보다 브랜드 인상이 약하고 데이터 서비스에 가깝게 보인다.
- 메인에서 필터를 많이 보여주면 결과 페이지와 역할이 겹칠 수 있다.

## 현재 권장 방향

A안을 메인 구조로 선택한다. B안의 조밀한 조건 선택은 결과 페이지의 역할로 남기고, 홈은 온천을 하고 싶은 마음과 발견에 집중한다.

권장 순서:

1. 공통 헤더 검색
2. 다섯 장면의 여행 감성 hero carousel
3. 세 개의 감정별 온천 후보 section
4. A안 지역 mosaic
5. A안 온천수 index
6. A안 evidence strip
7. 방법론 이미지 band

이 순서는 홈에서 욕구를 만들고, 지역과 온천수 방식으로 탐색을 넓힌 뒤, 데이터 현황과 방법론으로 신뢰를 마무리한다.
