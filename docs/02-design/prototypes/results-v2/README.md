# 바스타임 온천 결과 V2

`Evidence Workbench` 한 방향으로 만든 반응형 인터랙티브 HTML 시안입니다.

## 열기

- 비교 보드: `comparison.html`
- 시안 단독: `index.html`

## 포함 범위

- 데스크톱 고정 필터 레일
- 유형·목욕 구성·온천수·감촉·시설 조건, 지역은 상단 검색으로 접근
- 카드의 외부 후기 분석 수와 바스타임 자체 후기 수 분리
- 순수직수·직수·순환식 온천의 금·은·동 월계수 등급
- 선택 조건 제거와 전체 초기화
- 결과 수 갱신과 샘플 카드 필터링
- 추천·후기·온천수·이름 정렬
- 페이지 선택 상태
- 모바일 전체화면 필터 시트와 검색 패널
- 데스크톱 고정 지도와 모바일 전체화면 지도
- 필터 결과와 연동되는 지도 마커, 카드 포커스 이동
- `MapLibre + OpenFreeMap` 벡터 지도
- `한국어 → 영어 → 현지명` 순서의 지명 표시
