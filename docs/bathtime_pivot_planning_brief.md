# 바스타임 피벗 기획 정리 문서

## 1. 문서 목적

이 문서는 기존 바스타임 앱 기획을 **샤워·목욕 루틴 실행 앱**에서 **집 안팎의 바스타임을 더 좋게 만드는 내부 아카이브 + 실행 도구 + 장기 오프라인 전환 플랫폼**으로 재정의하기 위한 문서입니다.

기존 피벗 과정에서 “리추얼 카드 엔진”, “홈스파 사진 로그 앱”, “콘텐츠 매거진”, “예약/커머스 플랫폼” 등 여러 방향을 검토했습니다. 각 방향은 다음과 같은 한계가 있었습니다.

- 리추얼 카드 엔진: 기존 루틴 추천/타이머 앱과 차별이 약함
- 리추얼 로그 앱: 사진 오버레이 자체는 흥미롭지만 반복 사용 이유가 약함
- 순수 콘텐츠 매거진: 네이버 블로그, 인스타그램, 검색 콘텐츠와 차별화가 약함
- 커머스 플랫폼: 초기부터 제품 DB/제휴/구매 구조를 만들면 대형 플랫폼과 경쟁하게 됨
- 예약/쿠폰 플랫폼: 오프라인 제휴 영업, 낮은 객단가, 닭과 알 문제를 해결해야 함
- 커뮤니티 사이트: 로그인, 게시판, 댓글 등을 먼저 만들면 빈 커뮤니티가 될 위험이 큼
- 외부 SNS 중심 운영: 콘텐츠가 외부 플랫폼에 흩어져 내부 자산으로 축적되지 않음

이번 문서의 핵심은 다음과 같습니다.

> 바스타임은 앱 기능 하나로 문제를 해결하는 서비스가 아니라, 집 안팎에서 씻고 쉬는 시간을 더 좋게 만드는 방법, 장소, 아이템, 루틴을 내부에 축적하고, 필요한 순간 다시 찾아볼 수 있게 하는 바스타임 아카이브에서 출발한다. 장기적으로는 이 아카이브를 기반으로 실제 방문, 예약, 쿠폰, 키트 구매로 이어지는 전환 플랫폼을 지향한다.

P0에서는 거대한 예약/커머스 플랫폼을 만들지 않습니다. 우선 내부 웹/앱 아카이브에 콘텐츠와 구조화 데이터를 쌓고, 외부 채널은 유입과 홍보 채널로 활용합니다. 콘텐츠는 타이머, 저장, 제보 기능과 연결해 서비스의 기능적 이유를 만듭니다.

## 2. 최종 방향 한 줄

> **바스타임은 집 안팎의 바스타임을 더 좋게 만드는 기록과 도구를 모아둔 곳입니다.**

조금 더 사업적으로 풀면:

> 바스타임은 샤워, 족욕, 입욕, 홈스파, 사우나, 스파, 온천, 욕조 좋은 숙소까지, 씻고 쉬는 시간을 더 좋게 만드는 콘텐츠와 실행 도구를 내부에 축적하고, 장기적으로 실제 예약·방문·구매 전환까지 연결하는 바스타임 아카이브입니다.

## 3. 브랜드 미션

### 핵심 미션

> 씻고 쉬는 시간을 더 좋게 만들자.

### 확장 미션

> 한국에는 쉬고 싶은 사람은 많아지고 있지만, 좋은 사우나·스파·목욕·홈스파 경험을 찾고 즐기는 문화와 정보는 아직 충분히 정리되어 있지 않습니다. 바스타임은 집 안팎의 목욕, 샤워, 사우나, 홈스파 경험을 기록하고 제안해 더 좋은 바스타임 문화를 만들어갑니다.

### 브랜드가 바라보는 문제

- 대중탕은 오래되고 낡은 곳이 많아 젊은 사용자에게 매력적으로 다가오지 않음
- 좋은 사우나와 스파는 호텔 투숙객 전용, 회원 전용, 기업 복지시설 등으로 폐쇄적인 경우가 많음
- SNS에서 좋아 보이는 공간을 발견해도 실제 이용 조건, 가격, 외부인 이용 가능 여부를 알기 어려움
- 욕조 없는 집이 많아 입욕 중심 콘텐츠는 한국 시장에서 제한적임
- 홈스파, 족욕, 샤워 리추얼, 반신욕조, 사우나, 스파, 욕조 있는 숙소에 대한 정보가 흩어져 있음
- 사람들은 쉬고 싶지만, 어디서 어떻게 쉬면 좋은지 찾기 어렵다

### 브랜드가 만들고 싶은 문화

기존 목욕 문화가 “씻기”, “때 밀기”, “뜨거운 물”, “낡은 대중탕” 중심이었다면, 바스타임은 다음의 문화를 제안합니다.

> 씻고, 데우고, 조용히 쉬고, 몸을 회복하고, 좋은 공간을 찾아가고, 내 방식으로 기록하는 새로운 바스타임 문화.

## 4. 브랜드 전략 보완

브랜드 전문가 조언을 반영해, 바스타임은 단순 기능명이나 설명형 서비스명을 넘어 **기록과 검증의 브랜드**로 정리해야 합니다.

### 4.1 네이밍 재검토

현재 “바스타임 / Bath Time”은 직관적이지만, 지나치게 일반명사에 가깝고 검색 경쟁에서 묻힐 가능성이 있습니다. 장기 브랜드로 가져가려면 독자적인 이름을 검토해야 합니다.

네이밍 방향 후보:

- SŌAK 계열: 입욕, 머무름, 스며듦의 감각을 전달
- 沐(목) 계열: 씻다, 머리를 감다, 몸을 정화하다의 동양적 뉘앙스
- Archive 계열: 기록, 검증, 축적의 정체성 강조
- Bath + Record/Note/Archive 계열: 설명력과 브랜드성을 절충

주의:

- 최종 네이밍은 상표 등록 가능성, 검색 결과, 도메인, SNS 핸들, 국내 발음성을 별도 검토해야 한다.
- 현재 문서에서는 “바스타임”을 프로젝트명으로 유지하되, 출시 브랜드명은 재검토 대상으로 둔다.

### 4.2 “아카이브”를 브랜드 자산으로 사용한다

이 서비스의 가장 강한 차별점은 단순 추천이나 감성 콘텐츠가 아니라 **구조화된 기록**입니다.

인스타그램이 “발견”이라면, 바스타임은 “검증된 기록”이어야 합니다.

따라서 “아카이브”라는 개념을 브랜드 언어 전체에 녹입니다.

브랜드 언어 예시:

- 바스타임 아카이브
- 씻고 쉬는 시간을 위한 기록
- 직접 가보고, 찾아보고, 업데이트하는 바스타임 기록
- 외부인 이용 가능 여부까지 확인하는 사우나/스파 아카이브
- 흩어진 바스 경험을 다시 찾아볼 수 있게 정리합니다

### 4.3 초기 타깃은 한 사람으로 좁힌다

서비스 기획상으로는 홈스파 사용자, 사우나 탐색자, 욕실 아이템 관심자 등 여러 세그먼트가 존재합니다. 그러나 브랜드는 초기에 한 사람에게 말해야 합니다.

초기 브랜드 타깃:

> 퇴근 후 혼자만의 시간이 필요한 서울의 30대.

이 사람은 다음의 특성을 가집니다.

- 평일에는 바쁘고 피로가 쌓여 있음
- 사우나, 스파, 좋은 숙소, 바디케어 제품에 관심은 있지만 정보 탐색이 귀찮음
- 대중탕은 낡고 부담스럽게 느끼지만, 좋은 바스 경험에는 돈을 쓸 의향이 있음
- 집에서는 샤워나 족욕 정도가 현실적인 쉼의 방식임
- 주말이나 특별한 날에는 조용한 사우나, 스파, 욕조 있는 숙소를 찾고 싶어함

서비스는 넓게 확장하더라도, 초기 메시지는 이 사람에게 말하는 톤으로 유지합니다.

### 4.4 컬러 시스템 원칙

Deep Steam Navy와 Brass 조합은 브랜드에 잘 맞습니다.

다만 Brass를 과용하면 고급 스파나 황금빛 조명 이미지가 과해질 수 있습니다.

컬러 원칙:

- Deep Steam Navy를 지배색으로 사용
- Brass는 버튼, 강조선, 아이콘, 뱃지 등 포인트로만 사용
- 배경은 어둡고 깊게, 정보 영역은 차분하고 읽기 쉽게 구성
- 콘텐츠 아카이브 특성상 화려함보다 신뢰감, 깊이, 정돈감을 우선한다

### 4.5 첫 번째 콘텐츠 포맷을 고집스럽게 유지한다

브랜드는 반복으로 만들어집니다.

바스타임의 차별점은 “좋은 글”이 아니라 같은 기준으로 계속 정리되는 구조화된 정보입니다.

따라서 스팟 콘텐츠는 100개를 쓰더라도 같은 기본 포맷을 유지해야 합니다.

스팟 콘텐츠 고정 포맷:

- 외부인 이용 가능 여부
- 가격대
- 예약 필요 여부
- 위치/접근성
- 혼자 이용 적합도
- 커플/동행 이용 적합도
- 프라이빗 여부
- 시설 종류
- 좋았던 점
- 아쉬운 점
- 이런 사람에게 맞음
- 이런 사람에게는 애매함
- 업데이트 일자

홈 리추얼 콘텐츠 고정 포맷:

- 소요 시간
- 욕조 필요 여부
- 필요한 아이템
- 난이도
- 추천 상황
- 바로 실행 가능한 타이머
- 좋았던 점
- 아쉬운 점
- 이런 사람에게 맞음

이 일관성 자체가 “바스타임은 다르다”는 신호가 됩니다.

## 5. 핵심 운영 원칙: 외부 채널은 본진이 아니다

바스타임은 인스타그램, 스레드, 네이버 블로그, 숏폼 등 외부 채널을 적극 활용할 수 있습니다.

하지만 외부 채널은 콘텐츠의 원본 저장소가 아닙니다.

### 원칙

> 콘텐츠 원본은 바스타임 내부 웹/앱 아카이브에 쌓고, 외부 채널은 유입과 홍보를 위한 배포 채널로 사용한다.

### 이유

- 외부 플랫폼에만 콘텐츠를 올리면 장기 자산이 되기 어렵다
- 검색, 태그, 카테고리, 업데이트, 저장 기능을 바스타임 방식으로 설계할 수 없다
- 플랫폼 정책 변경, 노출 알고리즘 변화에 취약하다
- 바스타임의 핵심 자산은 “쌓여 있는 정보”와 “다시 찾아볼 수 있는 구조”이기 때문이다

### 채널 역할 분리

| 채널 | 역할 |
|---|---|
| 바스타임 웹/앱 | 콘텐츠 원본, 아카이브, 저장, 검색, 타이머 연결, 제보 접수 |
| 인스타그램/스레드/숏폼 | 콘텐츠 요약, 홍보, 유입, 반응 확인 |
| 검색/SEO | 문제 해결형 유입, 롱테일 검색 유입 |
| 뉴스레터/알림 | 재방문 유도, 업데이트 안내 |

## 5. 앱과 웹의 역할

멘토 피드백 중 중요한 지점은 “콘텐츠 중심 서비스라면 앱이어야 하는 이유가 있는가?”입니다.

이 지적은 타당합니다. 콘텐츠는 앱보다 웹에서 발견되고 소비되기 쉽습니다.

따라서 바스타임은 앱만을 본진으로 삼지 않습니다.

### P0 권장 구조

> P0의 본진은 웹 기반 바스타임 아카이브로 두고, 앱은 기존 타이머와 저장 기능을 통해 실행/보관 도구로 연결한다.

또는 개발 상황에 따라:

> 웹과 앱을 동일한 콘텐츠 구조로 운영하되, 웹은 유입과 탐색, 앱은 저장과 실행을 담당한다.

### 웹의 역할

- 검색 유입
- 외부 공유
- 콘텐츠 상세 소비
- 스팟/아이템 정보 탐색
- 제보 유입
- 앱 다운로드 전환

### 앱의 역할

- 저장한 콘텐츠 다시 보기
- 콘텐츠 기반 타이머 실행
- 최근 본 콘텐츠
- 관심 태그/카테고리
- 제보하기
- 향후 개인화/리마인더/커뮤니티 기능

### 앱 다운로드를 유도하는 이유

앱은 “글을 읽기 위해” 다운로드하는 것이 아닙니다.

앱의 이유는 다음입니다.

- 저장한 바스타임 콘텐츠를 다시 꺼내보기
- 콘텐츠에 연결된 타이머를 바로 실행하기
- 내게 맞는 샤워/족욕/입욕 세팅을 보관하기
- 나중에 제보, 방문 기록, 개인화 추천으로 확장하기

## 6. 기존 앱과 피벗의 관계

바스타임은 완전히 새로 시작하는 서비스가 아닙니다.

기존 앱에는 다음 자산이 있습니다.

- 샤워/목욕/족욕 타이머
- 컨디션 기반 루틴 콘텐츠
- Trip/무드형 테마 콘텐츠
- 제품 큐레이션 시도
- 완료/기록 화면
- 관리자 콘텐츠 관리 자산

다만 기존 구조의 중심은 다음과 같았습니다.

> 추천 → 실행 → 타이머 → 완료

새 피벗에서는 중심이 다음으로 바뀝니다.

> 콘텐츠 발견 → 저장/따라 하기 → 타이머 실행 → 제보/기록 → 아카이브 확장

즉, 타이머를 버리는 것이 아니라 **타이머의 위치를 바꿉니다.**

기존에는 타이머가 제품의 중심이었고, 이제는 콘텐츠를 실제 행동으로 이어주는 보조 도구가 됩니다.

## 7. 제품 정의

### 장기 제품 정의

> 바스타임은 집 안팎의 바스타임을 발견하고, 저장하고, 직접 따라 해볼 수 있게 돕는 바스 리추얼 아카이브입니다.

### P0 제품 정의

> 바스타임은 욕실에서 잘 쉬는 방법, 홈스파 세팅, 사우나·스파·숙소 경험, 욕실 아이템 정보를 내부 콘텐츠로 쌓고, 사용자가 관심 있는 콘텐츠를 바로 따라 해볼 수 있도록 타이머·저장·제보 기능을 연결하는 서비스입니다.

### 더 짧은 정의

> 좋은 바스타임을 발견하고, 저장하고, 바로 따라 해볼 수 있는 아카이브.

## 8. 핵심 전략: 콘텐츠와 기능을 엮는다

이번 피벗의 핵심은 콘텐츠와 기능의 관계를 다시 정의하는 것입니다.

### 기존 방식

> 기능이 먼저 있고, 사용자가 기능을 쓸 이유를 찾아야 했다.

예:

> 오늘 상태 선택 → 루틴 추천 → 타이머 실행

### 새로운 방식

> 콘텐츠가 욕구를 만들고, 기능이 그 욕구를 실제 행동으로 이어준다.

예:

> 욕조 없는 집의 10분 홈스파 글을 본다 → 나도 해보고 싶다 → 10분 족욕 타이머를 실행한다 → 괜찮았다면 저장하거나 내 세팅을 제보한다.

### 핵심 원칙

> 콘텐츠는 읽고 끝나는 글이 아니라, 기능을 부르는 입구여야 한다.

모든 콘텐츠에는 최소 하나의 행동이 연결되어야 합니다.

- 저장하기
- 타이머 시작하기
- 제보하기
- 비슷한 글 보기
- 관련 아이템 보기
- 스팟 저장하기

## 9. 리텐션 관점 재정의

멘토 피드백 중 두 번째 리스크는 “콘텐츠 아카이브는 재방문 동력이 약할 수 있다”는 점입니다.

이 지적은 일부 맞습니다. 하지만 바스타임을 반드시 매일 쓰는 앱으로 정의할 필요는 없습니다.

여행 서비스, 숙소 예약 서비스, 부동산 서비스처럼 매일 사용하지 않아도 필요한 순간 강한 가치를 제공하는 서비스가 있습니다.

바스타임도 다음처럼 정의할 수 있습니다.

> 바스타임은 매일 쓰는 루틴 앱이라기보다, 씻고 쉬는 시간을 더 좋게 만들고 싶을 때 찾아오는 바스타임 아카이브다.

### 리텐션을 3가지로 나눠본다

#### 1. 데일리 리텐션

매일 또는 주 2~3회 사용할 수 있는 콘텐츠/기능입니다.

- 수면 전 샤워
- 퇴근 후 족욕
- 운동 후 샤워
- 7분 리셋 타이머
- 오늘의 짧은 바스타임

#### 2. 시즌/상황 리텐션

특정 상황에서 다시 찾게 되는 콘텐츠입니다.

- 비 오는 날
- 겨울
- 주말
- 여행 전
- 운동 후
- 생일/기념일
- 휴가 전

#### 3. 의사결정 리텐션

구매나 방문, 예약 전에 찾아보는 콘텐츠입니다.

- 족욕기 살까?
- 반신욕조가 필요할까?
- 외부인 이용 가능한 사우나가 있을까?
- 욕조 있는 숙소를 어떻게 고를까?
- 프라이빗 스파룸은 돈값을 할까?

### 결론

바스타임은 데일리 리텐션만으로 승부하지 않습니다.

> 데일리 홈 리추얼은 앱 재방문을 방어하고, 스팟/아이템/숙소 콘텐츠는 검색과 의사결정 순간의 재방문을 만든다.

## 10. 핵심 타겟

### 초기 브랜드 타깃

브랜드 초반에는 여러 사람에게 동시에 말하지 않습니다.

초기 타깃은 다음 한 사람으로 좁힙니다.

> 퇴근 후 혼자만의 시간이 필요한 서울의 30대.

이 타깃은 바스타임이 가장 먼저 설득해야 할 사람입니다.

### 이 사람의 상황

- 평일에는 바쁘고 피로가 쌓여 있음
- 집에서는 샤워나 족욕 정도가 현실적인 쉼의 방식임
- 좋은 사우나, 스파, 욕조 있는 숙소에 관심이 있지만 찾는 과정이 번거로움
- 대중탕은 오래되고 낡은 이미지 때문에 선뜻 가기 어려움
- SNS에서 좋은 공간을 발견해도 실제 이용 가능 여부를 확인하기 어렵다고 느낌
- 쉬고 싶지만 어디서 어떻게 쉬면 좋을지 정리된 정보를 원함

### 확장 가능한 세그먼트

초기 메시지는 한 사람에게 집중하지만, 서비스 데이터와 콘텐츠는 다음 세그먼트로 확장될 수 있습니다.

- 집에서 홈스파를 시도하고 싶은 사용자
- 사우나·스파·찜질방을 찾는 사용자
- 욕조 있는 숙소를 찾는 사용자
- 입욕제, 족욕기, 반신욕조, 욕실 아이템을 고민하는 사용자
- 운동 후 회복이나 수면 전 루틴에 관심 있는 사용자

### 핵심 욕구

- 욕조가 없어도 집에서 쉬는 느낌을 만들고 싶다
- 좋은 사우나나 스파를 찾고 싶다
- SNS에서 본 공간이 실제 이용 가능한지 알고 싶다
- 욕조 있는 숙소를 고를 때 참고하고 싶다
- 입욕제, 향초, 족욕기, 반신욕조 같은 아이템을 실제로 쓸 만한지 알고 싶다
- 나중에 따라 해볼 만한 바스타임 콘텐츠를 저장하고 싶다

## 12. 구조적 차별화: 네이버 블로그·인스타그램·스테이폴리오와 무엇이 다른가

멘토 피드백 중 가장 중요한 리스크는 대체재의 위협입니다.

사람들은 이미 네이버에서 “서울 깨끗한 사우나”를 검색하고, 인스타그램에서 감성 숙소와 스파 사진을 저장하며, 스테이폴리오에서 좋은 숙소를 찾습니다.

따라서 바스타임은 단순히 톤 좋은 글을 쓰는 웹진이어서는 안 됩니다.

바스타임의 차별화는 **구조화된 바스타임 데이터**에서 나와야 합니다.

### 네이버 블로그와의 차이

네이버 블로그:

- 개인 후기 중심
- 광고성 글이 많음
- 정보가 흩어져 있음
- 최신성 확인이 어려움
- 외부인 이용 가능 여부, 예약 필요 여부 등이 구조화되어 있지 않음

바스타임:

- 바스타임 경험 중심의 구조화된 아카이브
- 외부인 이용 가능 여부, 가격, 예약, 위치, 적합 상황을 항목화
- 콘텐츠 업데이트 이력 관리
- 장소/아이템/홈 리추얼을 태그로 연결

### 인스타그램과의 차이

인스타그램:

- 이미지 중심
- 실제 이용 조건이 부족함
- 검색과 비교가 어려움
- 저장은 가능하지만 의사결정 정보가 약함

바스타임:

- 예쁜 장면뿐 아니라 실제 이용 가능성과 조건을 정리
- “좋아 보이는 곳”이 실제로 누구에게 열려 있는지 확인
- 상황별 탐색 가능: 혼자 쉬기, 외부인 이용 가능, 욕조 있는 숙소, 수면 전, 운동 후 등

### 스테이폴리오와의 차이

스테이폴리오:

- 감성 숙소 중심
- 숙소 전체 경험 중심
- 바스/사우나/스파 경험만을 깊게 다루지는 않음

바스타임:

- 숙소 전체가 아니라 “씻고 쉬는 경험”에 초점
- 욕조, 사우나, 스파, 자쿠지, 온천, 홈스파 세팅을 연결
- 집 안팎의 바스타임을 하나의 관점으로 묶음

### 바스타임만의 핵심 데이터 항목

스팟 콘텐츠에서 구조화해야 할 데이터:

- 외부인 이용 가능 여부
- 투숙객/회원 전용 여부
- 가격대
- 예약 필요 여부
- 위치/접근성
- 혼자 이용 가능 여부
- 커플/동행 이용 적합성
- 프라이빗 여부
- 시설 노후도/청결도
- 혼잡도
- 휴대폰 사용 가능 여부
- 사우나/스파/욕조/자쿠지/족욕 시설 종류
- 수면 전/운동 후/데이트/혼자 쉬기 적합도
- 준비물/이용 팁
- 최신 운영 정보 업데이트 일자

아이템 콘텐츠에서 구조화해야 할 데이터:

- 사용 상황
- 욕조 필요 여부
- 보관/청소 난이도
- 매일 사용 가능성
- 가격대
- 추천 대상
- 비추천 대상
- 함께 쓰기 좋은 세팅

홈 리추얼 콘텐츠에서 구조화해야 할 데이터:

- 소요 시간
- 욕조 필요 여부
- 필요한 아이템
- 난이도
- 추천 상황
- 바로 실행 가능한 타이머 연결 여부

### 결론

> 바스타임은 예쁜 정보를 보여주는 곳이 아니라, 실제로 씻고 쉬는 경험을 실행할 수 있도록 조건과 맥락을 구조화하는 곳이다.

## 13. 콘텐츠 톤: 매거진보다 블로그형 아카이브

바스타임은 초기에 공신력 있는 전문 매거진처럼 보일 필요가 없습니다.

오히려 다음 톤이 더 자연스럽습니다.

> 욕실에서 잘 쉬는 방법을 직접 찾아보고 정리하는 블로그형 아카이브.

### 피해야 할 톤

- 에디터가 엄선한 프리미엄 홈스파 리추얼
- 전문가가 추천하는 완벽한 수면 입욕법
- 의학적 효능을 강조하는 건강관리 콘텐츠
- 광고성 제품 소개
- 너무 고급스럽고 거리감 있는 매거진 톤

### 지향할 톤

- 해봤다
- 찾아봤다
- 정리했다
- 다녀왔다
- 제보받았다
- 업데이트했다
- 솔직히 좋았던 점과 아쉬운 점을 함께 말한다

### 문체 예시

나쁜 예:

> 에디터가 추천하는 프리미엄 홈스파 리추얼.

좋은 예:

> 욕조 없는 집에서도 좀 쉬는 느낌이 날까 싶어서 족욕 세팅을 해봤다.

나쁜 예:

> 수면 개선에 도움을 주는 과학적 입욕법.

좋은 예:

> 자기 전에 샤워만으로도 좀 차분해질 수 있을까?

## 14. 콘텐츠 생산 구조: 런닝머신을 피하는 방식

멘토 피드백 중 네 번째 리스크는 콘텐츠 생산이 운영자에게 과도한 노동이 될 수 있다는 점입니다.

이 지적은 맞습니다. 따라서 바스타임의 콘텐츠 운영은 매번 새로운 글을 창작하는 방식이 아니라 **수집, 정리, 검증, 업데이트** 중심으로 설계해야 합니다.

### 14.1 콘텐츠 생산 방식

#### 1. 직접 경험형

직접 다녀오거나 써본 것.

- 신뢰도 높음
- 생산량은 적어도 됨

#### 2. 리서치 정리형

공개 정보, 후기, 공식 사이트, SNS 정보 등을 정리.

- 생산성이 높음
- 아카이브에 적합

#### 3. 제보 검증형

유저 제보를 확인하고 바스타임식 콘텐츠로 재가공.

- 커뮤니티 씨앗
- 운영자가 품질 관리 가능

#### 4. 업데이트형

기존 글을 최신화.

- 콘텐츠 수명을 늘림
- 아카이브 가치 상승

예:

> 외부인 이용 가능한 서울 호텔 사우나 리스트 — 2026.05 업데이트

### 14.2 반복 가능한 콘텐츠 포맷

- 리스트형
- 비교형
- 후기형
- 체크리스트형
- 제보 재가공형
- 업데이트형

### 14.3 운영 루틴 예시

현실적인 주간 운영 예시:

```txt
월: 짧은 홈 리추얼 콘텐츠 1개
수: 아이템/정보 정리 1개
금: 스팟/숙소/사우나 콘텐츠 1개
일: 외부 SNS용 요약 카드/숏폼 1개
```

### 14.4 콘텐츠 재활용 원칙

하나의 원본 콘텐츠를 여러 채널로 재활용합니다.

예:

> 욕조 없는 집에서 10분 홈스파

재활용:

- 바스타임 내부 원본 글
- 인스타 카드뉴스
- 스레드 짧은 글
- 앱 콘텐츠 카드
- 뉴스레터/푸시 문구

## 15. 콘텐츠 포맷

### 15.1 해봤다

직접 경험 기반 콘텐츠.

- 샤워 전에 조명만 낮춰도 분위기가 바뀔까?

### 15.2 찾아봤다

정보 탐색/리서치형 콘텐츠.

예:

- 서울에서 조용히 쉬기 좋은 사우나를 찾아봤다
- 욕조 있는 숙소를 고를 때 체크할 것들
- 외부인도 이용 가능한 호텔 사우나가 있을까?

### 15.3 정리했다

정보 정리형 콘텐츠.

예:

- 족욕기와 반신욕조 차이 정리
- 입욕제 종류별 차이
- 욕실 트레이 고를 때 보는 기준

### 15.4 다녀왔다

스팟 방문 후기.

예:

- ○○ 사우나 다녀온 후기
- 욕조 있는 숙소를 써보고 느낀 점
- 프라이빗 스파룸은 돈값을 할까?

### 15.5 제보받았다

커뮤니티 씨앗 콘텐츠.

예:

- 제보받은 서울 사우나 리스트
- 독자 제보: 원룸 욕실에서 홈스파하는 방법
- 사람들이 추천한 욕실 아이템

### 15.6 업데이트했다

기존 콘텐츠 최신화.

예:

- 외부인 이용 가능한 서울 사우나 리스트 업데이트
- 2026년 기준 욕조 있는 숙소 체크리스트
- 최근 운영 정보가 바뀐 스파/사우나 정리

## 20. 제보 기능

멘토 피드백 중 세 번째 리스크는 “제보하기의 허들이 높다”는 점입니다.

이 지적은 맞습니다. 따라서 P0의 제보는 긴 후기 작성이 아니라 **사진 1장, 링크 1개, 한 줄 코멘트** 수준으로 시작합니다.

### P0 제보 원칙

- 사용자가 완성된 콘텐츠를 작성하게 하지 않는다
- 사용자는 단서를 던지고, 운영자가 정리한다
- 처음에는 바로 공개하지 않는다
- 제보는 커뮤니티가 아니라 아카이브를 함께 채우는 참여 행위로 표현한다

### 제보 폼 필드

공통:

```txt
제보 유형
- 사우나/스파
- 욕조 있는 숙소
- 홈스파 세팅
- 아이템
- 다뤄줬으면 하는 주제

사진 1장 또는 링크 1개
한 줄 코멘트
닉네임 선택 입력
공개 가능 여부
```

### 제보 CTA 문구

- 이런 곳 아세요? 한 줄로 알려주세요.
- 다녀온 곳이 있다면 이름만 남겨주세요. 바스타임이 확인해볼게요.
- 좋았던 사우나, 욕조 있는 숙소, 홈스파 세팅을 알려주세요.
- 바스타임 아카이브를 함께 채워주세요.

### 제보 동기

초기에는 금전 보상보다 인정 욕구와 소속감을 활용합니다.

가능한 장치:

- BATH TIME First Bathers
- “OO님이 알려준 곳” 표기
- 제보 채택 시 소액 리워드
- 월간 제보자 소개

## 21. 수익화 전략: 콘텐츠 트래픽이 아니라 전환을 만든다

멘토 피드백 중 가장 중요한 질문은 다음입니다.

> 웹 아카이브를 통해 트래픽과 제보가 쌓였을 때, 유저의 지갑을 열게 만들 첫 번째 킬러 수익 모델은 무엇인가?

바스타임은 콘텐츠 트래픽 자체를 광고로 팔려는 서비스가 아닙니다.

바스타임의 수익화 핵심은 다음입니다.

> 좋은 바스타임을 발견한 사용자가 실제로 예약하거나, 방문하거나, 구매하게 만드는 전환 구조.

### 21.1 1차 킬러 수익 모델: 바스타임 장소 예약/쿠폰 전환

가장 우선 검토할 수익 모델은 외부 공간의 예약/쿠폰 전환입니다.

대상:

- 외부인 이용 가능한 사우나
- 프라이빗 스파룸
- 호텔 사우나/스파 패키지
- 욕조 좋은 숙소
- 자쿠지/풀빌라
- 온천/스파 시설
- 커플 스파
- 1인 휴식 공간

수익 방식:

- 예약 전환 수수료
- 제휴 쿠폰 판매
- 체험권 판매
- 입점 광고
- 프리미엄 노출
- 시즌 기획전

핵심은 대중 사우나 전체를 처음부터 제휴하는 것이 아니라, **객단가와 차별성이 있는 공간부터 선별**하는 것입니다.

### 21.2 2차 수익 모델: 홈스파 리추얼 키트

집에서 쉬고 싶은 사용자를 위한 키트형 커머스입니다.

예:

- 욕조 없는 집 홈스파 스타터 키트
- 수면 전 족욕 키트
- 운동 후 회복 샤워 키트
- 비 오는 밤 샤워 리추얼 키트
- 반신욕조 입문 세트
- 선물용 바스타임 박스

초기에는 자체 재고를 들고 가지 않습니다.

검증 순서:

1. 콘텐츠 내 관심도 측정
2. 알림받기/사전 신청
3. 프리오더
4. 브랜드 협업
5. 소량 판매

### 21.3 3차 수익 모델: 브랜드/공간 협업 콘텐츠

트래픽과 신뢰가 쌓이면 브랜드와 공간 사업자가 바스타임 안에서 맥락 있는 노출을 원할 수 있습니다.

수익 방식:

- 브랜드 협업 콘텐츠
- 스팟 소개 패키지
- 체험단 모집
- 리추얼 기획전
- 바스타임 추천/인증 뱃지

단, 초기에 광고성 콘텐츠로 보이면 신뢰를 잃을 수 있으므로 명확한 표시와 편집 기준이 필요합니다.

## 22. 오프라인 제휴 리스크와 GTM 전략

멘토 피드백 중 가장 현실적인 리스크는 오프라인 영업입니다.

좋은 UI/UX와 웹/앱 개발은 비교적 빠르게 만들 수 있지만, 실제 수익화는 화면 밖에서 발생합니다.

### 22.1 리스크: B2B 영업의 난이도

로컬 사우나, 스파, 찜질방, 숙소 업주는 IT 서비스에 익숙하지 않을 수 있습니다.

그들에게 수수료 모델, 예약 연동, 쿠폰 시스템을 설명하고 도입시키는 것은 단순한 기획이 아니라 대면 영업의 영역입니다.

### 대응 원칙

P0에서는 제휴를 전제로 하지 않습니다.

우선 공개 정보와 직접 조사, 제보를 기반으로 아카이브를 만들고, 트래픽과 저장 데이터를 확보한 뒤 제휴를 제안합니다.

초기 제휴는 다음 조건의 공간을 우선합니다.

- 이미 SNS/온라인 홍보 의지가 있는 곳
- 객단가가 너무 낮지 않은 곳
- 외부인 이용이 가능한 곳
- 예약/문의 흐름이 존재하는 곳
- 프라이빗 스파, 1인 사우나, 숙소, 웰니스 공간처럼 차별성이 있는 곳

### 22.2 리스크: 수수료와 거래액의 딜레마

대중 사우나:

- 객단가 낮음
- 방문 빈도는 상대적으로 높을 수 있음
- 수수료 수익이 작음
- 많은 거래량이 필요함

프라이빗 스파/숙소:

- 객단가 높음
- 수수료 수익이 큼
- 방문 빈도 낮음
- 의사결정 시간이 길 수 있음

### 초기 타겟 판단

초기 현금 흐름을 만들기 위해서는 저가 대중 사우나보다 **중고가·차별화 공간**을 먼저 검토합니다.

우선순위:

1. 프라이빗 스파룸
2. 욕조/자쿠지 좋은 숙소
3. 외부인 이용 가능한 호텔 사우나/스파
4. 감성 사우나/웰니스 공간
5. 이후 지역 대중 사우나/찜질방

### 22.3 리스크: 닭과 알 문제

제휴 공간을 확보하려면 트래픽이 필요하고, 트래픽을 만들려면 매력적인 공간 정보가 필요합니다.

### 대응 전략

1. 제휴 없이도 만들 수 있는 공개 아카이브부터 구축한다.
2. “외부인 이용 가능 여부”, “가격”, “예약 필요 여부” 같은 구조화 데이터를 먼저 축적한다.
3. 특정 지역 또는 카테고리로 좁혀 신뢰 있는 리스트를 만든다.
4. 리스트 조회수, 저장 수, 문의 클릭 수를 근거로 공간 업주에게 제안한다.
5. 예약 연동이 어려우면 처음에는 쿠폰 코드, 전화 문의, 네이버 예약 링크 추적 등 가벼운 방식으로 시작한다.

## 23. 초기 GTM 전략

### 23.1 지역을 좁힌다

전국 단위로 시작하지 않습니다.

초기에는 특정 지역을 잡습니다.

예:

- 서울 강서/마곡/홍대/성수/강남 등 특정 상권
- 수도권 외부인 이용 가능 사우나
- 서울 욕조 있는 숙소
- 경기권 프라이빗 스파룸

지역을 좁혀야 실제 방문, 확인, 업데이트, 제휴 영업이 가능합니다.

### 23.2 카테고리를 좁힌다

처음부터 모든 바스 경험을 다루지 않습니다.

초기 집중 후보:

1. 외부인 이용 가능한 사우나/스파
2. 욕조 있는 숙소
3. 욕조 없는 집 홈스파

이 세 축은 각각 역할이 다릅니다.

- 외부인 이용 가능한 사우나/스파: 스팟 아카이브와 제휴 가능성
- 욕조 있는 숙소: 객단가와 예약 전환 가능성
- 욕조 없는 집 홈스파: 데일리 리텐션과 콘텐츠 확장성

### 23.3 제휴 전환 전 가벼운 수익 실험

초기부터 완전한 예약 시스템을 만들지 않습니다.

가벼운 실험:

- 제휴 쿠폰 코드
- 예약/문의 버튼 클릭 추적
- 네이버 예약 링크 클릭 추적
- 사전 신청/알림받기
- 프리오더형 홈스파 키트
- 브랜드 협업 콘텐츠 테스트

## 28. 최종 정리

바스타임은 더 이상 단순 샤워·목욕 루틴 앱이 아닙니다.

그렇다고 처음부터 커뮤니티나 커머스 플랫폼을 만들 필요도 없습니다.

지금 가장 현실적인 방향은 다음입니다.

> 바스타임은 집 안팎에서 씻고 쉬는 시간을 더 좋게 만드는 내부 콘텐츠 아카이브로 시작하고, 콘텐츠를 타이머·저장·제보 기능과 연결해 플랫폼의 씨앗을 만든다. 이후 구조화된 스팟/아이템 데이터를 기반으로 예약, 쿠폰, 키트, 제휴 전환을 검증한다.

### 최종 포지셔닝

> 바스타임은 좋은 바스타임을 발견하고, 저장하고, 바로 따라 해볼 수 있는 아카이브입니다.

### 장기 수익화 포지셔닝

> 바스타임은 좋은 바스타임 경험을 발견한 사용자가 실제 방문, 예약, 구매로 이어지도록 돕는 전환 플랫폼을 지향합니다.

### 핵심 성공 조건

- 콘텐츠 원본은 내부에 쌓아야 한다
- 외부 채널은 유입과 홍보 채널로만 사용한다
- 기능은 콘텐츠를 행동으로 이어주는 역할이어야 한다
- 타이머는 중심이 아니라 보조 도구여야 한다
- 제품은 쇼핑 탭이 아니라 콘텐츠 속 아이템 맥락으로 들어가야 한다
- 커뮤니티는 게시판이 아니라 초간단 제보로 시작해야 한다
- 콘텐츠 생산은 창작보다 수집, 정리, 검증, 업데이트 중심이어야 한다
- 욕실 내부만이 아니라 사우나, 스파, 온천, 욕조 있는 숙소까지 확장해야 한다
- 네이버/인스타와의 차별화는 구조화된 바스타임 데이터에서 나온다
- 수익화는 콘텐츠 광고가 아니라 예약/쿠폰/키트/제휴 전환에서 검증한다
- 오프라인 제휴는 초기부터 대규모로 추진하지 않고, 특정 지역·고객가치 높은 공간부터 좁게 검증한다
- 브랜드는 “씻고 쉬는 시간을 더 좋게 만들자”라는 미션을 유지해야 한다
