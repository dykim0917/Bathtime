# Content UX Polish Guidelines

바스타임 콘텐츠 제작 파이프라인 공통 UX 검수 원칙입니다.

이 문서는 스팟가이드팀, 아이템팀, 문화팀, 이후 신설되는 모든 콘텐츠 제작 세션에 적용합니다.

## Goal

콘텐츠를 단순한 글이 아니라 독자가 읽고, 저장하고, 다음 행동까지 이어갈 수 있는 웹 콘텐츠로 다듬습니다.

검수 범위는 문장 품질뿐 아니라 이미지 캡션, 한눈에 보기 요약, 리스트 가독성, CTA를 포함합니다.

## Image Captions

독자-facing 캡션에서는 제작 방식을 강조하지 않습니다.

피합니다.

- `비브랜드 생성 이미지입니다`
- `생성형 AI로 만든 이미지입니다`
- `제작된 이미지입니다`
- `실제 시설 사진이 아닙니다`

대신 이미지가 콘텐츠 안에서 어떤 메시지를 돕는지 설명합니다.

예:

- 정보가 흩어져 있어 나에게 맞는 사우나를 찾기 어려운 상황을 보여주는 장면
- 방문 전 확인해야 할 조건들을 한눈에 떠올리게 하는 이미지
- 제품을 고를 때 놓치기 쉬운 기준을 시각적으로 정리한 이미지
- 씻는 시간이 하루의 경계가 되는 순간을 보여주는 장면

실제 방문 사진, 실제 제품 사용 사진처럼 오해될 수 있는 경우에만 자연스럽게 투명성을 보완합니다.

예:

- 특정 장소를 가리키는 이미지는 아니지만, 방문 전 확인할 조건을 떠올리기 위한 장면입니다.

## Lists And Checklists

확인 항목, 기준, 소스 유형, 비교 포인트가 나열될 때는 단순 bullet list로만 길게 늘어놓지 않습니다.

가능하면 아래 형식을 사용합니다.

- 항목 앞에 짧은 라벨 붙이기
- 핵심어를 먼저 쓰고 설명 붙이기
- 체크리스트형 문장으로 정리하기
- ArchiveContent에서 지원하는 block 형태 활용하기

예:

- 공식 안내: 이용 자격, 운영 시간, 휴관 여부를 먼저 확인합니다.
- 공공데이터: 영업 상태나 인허가 정보를 참고합니다.
- 지도·예약 플랫폼: 최근 운영 흔적과 후기 흐름을 보조로 봅니다.

아이콘, 미니 태그, 체크리스트 카드 UI가 필요하지만 현재 렌더러가 지원하지 않으면 억지로 구현하지 않고 `publish_blockers` 또는 `quality.ux_follow_up`에 남깁니다.

## Structured Overview

특정 장소, 제품, 루틴 콘텐츠는 기존 `한눈에 보기` 정보를 적극 사용합니다.

기준, 인사이트, 문화, 용어 콘텐츠는 기본 메타데이터가 독자에게 도움이 되는지 검토합니다.

도움이 약한 경우 `quality.ux_follow_up` 또는 `publish_blockers`에 추천 요약을 남깁니다.

예:

- 카테고리: 공간 가이드
- 대상: 혼자 조용히 쉬고 싶은 사람
- 핵심 키워드: 사우나 검증 기준
- 읽고 나면: 방문 전 확인할 조건을 알 수 있음

현재 스키마나 렌더러가 지원하지 않는 값을 억지로 넣지 않습니다.

## CTA

모든 콘텐츠는 하단에서 독자가 다음 행동을 할 수 있어야 합니다.

스팟가이드 예:

- 내가 가본 진짜 쉬기 좋았던 사우나 제보하기
- 다음 사우나 가이드 알림 받기
- 외부인 이용 가능 여부 확인법 이어서 보기

아이템 노트 예:

- 이 기준으로 제품 후보 더 보기
- 써본 제품 제보하기
- 다음 아이템 노트 알림 받기

문화/읽을거리 예:

- 다음 바스타임 이야기 읽기
- 나만의 바스타임 습관 제보하기
- 관련 용어/가이드 이어서 보기

실제 링크나 라우트가 없으면 버튼처럼 구현하지 않습니다. 링크가 준비되지 않은 CTA는 본문 텍스트 또는 `publish_blockers`에 남깁니다.

## Final Checklist

Draft apply 전 확인합니다.

- 이미지 캡션이 제작 방식보다 콘텐츠 메시지를 설명하는가
- 이미지가 실제 장소, 제품, 방문 사진처럼 오해되지 않는가
- 긴 리스트가 단순 나열로만 보이지 않는가
- 확인 항목에는 라벨이나 구조가 있는가
- `한눈에 보기` 박스가 이 콘텐츠 유형에 적합한가
- 부적합하다면 `quality.ux_follow_up` 또는 `publish_blockers`에 기록했는가
- 하단 CTA가 있는가
- CTA 링크가 실제로 존재하는가
- 없는 링크를 버튼처럼 만들지 않았는가
- 브랜드명은 `바스타임`으로 되어 있는가
- 직접 방문/직접 사용한 것처럼 오해될 문장이 없는가
