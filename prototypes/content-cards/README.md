# 실제 저장 링크 → 목욕 장소 카드

2026-09-22, 사용자가 보낸 링크 3개를 직접 확인해 만든 로컬 샘플입니다.

현재 디자인 기준: [모바일 전용 피벗 디자인 방향](../../docs/02-design/bathtime-pivot-design-direction.md). 오늘의집·화해처럼 밝고 청량한 시각 방향, 토스처럼 간결한 문구를 적용합니다. 이전 단계의 종이색 배경과 데스크톱 3열·태블릿 2열 분기는 제거했습니다. PC에서도 동일한 최대 440px 모바일 화면을 보여줍니다.
`node prototypes/content-cards/preview.cjs` 실행 후 http://127.0.0.1:3218/ 에서 확인합니다.
별도 빌드나 패키지 설치 없이 `index.html`을 직접 열어도 동작합니다.

## 확인할 사용성

- 원문의 계정명 대신 실제 장소명을 카드 제목으로 보여줍니다.
- 장소 종류·지역 필터, 이름·특징·작성자 검색으로 다시 찾습니다. 검색은 준비된 텍스트 검색이며 AI 검색이 아닙니다.
- 목록 → 장소 상세 → 저장한 원문 / Google 지도 검색 / 공식 안내로 이어집니다.
- 작성자와 원문 URL은 보존합니다. 지도 링크는 이름·주소 검색이며 검증한 Google Place ID가 아닙니다.
- 남성 전용, 여성 사우나, 온탕 없음처럼 선택을 바꾸는 조건을 앞에 둡니다.
- 운영 정보가 원문에 없으면 채워 넣지 않습니다. 과거 가격·시간은 게시일과 함께 표시합니다.

## 언어와 정보 구성 — 2026-09-22 1차 개선

사용자 선택: 보관함은 **장소·제품 중심**으로 보여주고, 각각의 상세에서 저장한 게시물을 확인합니다. 현재는 실제 자료가 있는 장소 3개만 적용했습니다.

| 화면 | 먼저 보여줄 내용 | 문구 기준 |
| --- | --- | --- |
| 보관함 | 장소명, 지역, 한 줄 소개, 특징, 주요 이용 조건 | 무엇이고 어디인지 먼저. 감상이나 방문 의도는 추측하지 않기 |
| 상세 | 내용 요약 → 이용 정보 → 저장한 게시물 → 출처·확인일 | 제목만 읽어도 내용이 예상되는 이름 사용 |
| 원문 연결 | 작성자, 플랫폼, 원문 URL | 앱 안의 상세 보기와 외부 게시물 보기를 구분 |

- 탐색 문구는 짧게: ‘내 보관함’, ‘장소’, ‘상세 보기’, ‘게시물 보기’.
- 한 줄 소개는 특징을 설명하는 구절, 상세 설명은 해요체, 정보 표는 짧은 값으로 씁니다.
- 추천 근거 없이 ‘남겨둘 만한’, ‘이럴 때 가면 좋은’ 등의 판단을 넣지 않습니다.
- 공식 안내의 ‘확인’과 작성자의 ‘소개’를 구분합니다. 확인하지 못한 항목은 정보 없음으로 남깁니다.
- 자동 자막 오류 처리 같은 조사 과정은 이 문서에 보관합니다. 제품 화면에는 출처·확인일만 둡니다.
- 요금과 운영시간에는 게시 시점을 표시합니다. 공식 안내를 근거로 한 항목은 해당 페이지로 바로 연결합니다.
- 검색 결과 없음은 저장한 자료 없음과 구분합니다. 조건이 남아 있을 때는 초기화 버튼을 제공합니다.

다음에 실제 예시로 구체화할 항목: 제품에서 필요한 정보, 한 게시물에 장소가 여러 개인 경우, 같은 장소의 게시물이 추가되는 경우. 현재 3건만으로 세부 분류 체계를 확정하지 않습니다.

## 구현 범위

정적 예시 데이터 + 필터/검색 + 상세 대화상자입니다. 자동 수집·분석, 서버 저장, 로그인, DM, 공개 DB 발행, 네이티브 APK 변경은 없습니다. 브라우저에서 원문을 읽은 결과가 향후 API로 동일하게 수집된다는 뜻은 아닙니다.
샘플은 장소 3개만 포함합니다. 제품·팁 분류는 실제 예시가 들어왔을 때 설계합니다.

향후 DB 연결 시 장소 식별자와 원문 식별자를 분리하고, 사용자별 저장 관계를 따로 둡니다. 이번 샘플은 1:1 데이터지만 한 장소의 원문 여러 개 / 한 원문의 장소 여러 개도 합치거나 나눌 수 있어야 합니다.

## 확인 결과

데스크톱 및 390×844 모바일 크기에서 확인했습니다. 이미지 3개 로딩, 세신 검색 → 청담 1개, 도쿄 필터 → SHIAGARU 1개, 사우나 필터 → 2개, 빈 검색 결과와 전체 보기 복원 → 3개가 정상입니다. 상세 원문·지도·공식 안내의 URL과 새 창 속성을 확인했고, Escape 닫기와 닫기 버튼 초기 초점을 확인했습니다. 모바일 가로 넘침과 브라우저 콘솔 오류는 없었습니다. 외부 지도 검색 결과의 장소 일치 여부까지 검증한 것은 아닙니다.

1차 문구·정보 개선 후에는 360×800, 820×900에서 다시 확인했습니다. ‘서울 세신’ 복합 검색, 종류+지역 필터, 빈 결과 문구, 검색·필터 초기화, 상세의 초기 초점과 스크롤 후 고정 닫기 버튼을 확인했습니다. 820px에서는 카드 2열, 작은 휴대폰에서는 1열이며 가로 넘침과 콘솔 오류가 없었습니다. 공식 근거 항목의 링크와 카드에서 게시물로 연결되는 URL도 확인했습니다.

모바일 전용 시안 적용 후 360×800, 390×844, 430×932에서 확인했습니다. 사진 중심 2열 카드, 전체 높이 상세, 최소 44px 필터·닫기 버튼과 52px 하단 버튼, 검색·빈 결과·전체 보기·지역 필터를 확인했습니다. 가로 넘침과 콘솔 오류가 없었습니다. 작성자 정보와 출처는 상세에 유지하고, 목록의 외부 링크는 플랫폼 이름으로 표시합니다.
