# 장성그랜드사우나 Image Placement Plan

상태: 사진 권리 미확인. 발행 전 이미지 사용 허가 또는 자체 촬영 필요.

## Image Policy

- 네이버 블로그, 지도, Trip.com, 검색 결과 이미지는 무단 사용하지 않는다.
- 목욕탕/찜질방 특성상 탈의실, 목욕탕 내부, 이용객 얼굴, 반신 노출 가능 공간 이미지는 사용하지 않는다.
- 내부 사진이 필요하면 운영자 허가를 받고 사람이 없는 공용 휴게공간만 촬영한다.
- 발행 전 공식 제공 이미지 또는 직접 촬영 이미지의 사용 범위를 문서화한다.

## Recommended Image Slots

| 위치 | 이미지 목적 | 권장 이미지 | 대체안 | 주의 |
|---|---|---|---|---|
| Hero | 장소 식별 | 외부 간판 또는 장성빌딩 입구 | 생성 이미지: 장승배기 로컬 찜질방 입구 분위기 | 상호/간판 촬영 허가 확인 |
| Quick Facts | 접근성 | 장승배기역 5번 출구 또는 주변 골목 | 지도 캡처 대신 텍스트 지도 카드 | 지도 캡처 저작권 주의 |
| Facility Section | 목욕/찜질 경험 | 찜질방 공용 휴게공간, 만남의 광장, 테이블 공간 | 생성 이미지: 온돌 휴게공간의 조용한 스케치 | 이용객 노출 금지 |
| Food Section | 매점/푸드코트 | 식혜, 컵라면, 매점 메뉴판 | 직접 촬영한 음식 클로즈업 | 메뉴판 가격은 최신성 확인 필요 |
| Verification Note | 확인 필요 | 전화번호/입구 안내문 일부 | 아이콘형 체크리스트 그래픽 | 개인정보/이용객 노출 금지 |

## Suggested Shot List For Direct Visit

1. 건물 외부와 입구 간판.
2. 장승배기역에서 오는 길의 방향성 있는 컷.
3. 사우나 입구 외부 안내판.
4. 요금표와 이용 안내문. 가격 정보 발행 동의 확인 필요.
5. 푸드코트/매점 메뉴판. 이용객 얼굴이 나오지 않게 촬영.
6. 식혜나 간단한 매점 음식 클로즈업.
7. 공용 휴게공간은 사람이 없는 시간대에만 촬영.

## Generated Image Fallback

직접 촬영 또는 허가 이미지를 확보하지 못하면 다음처럼 “실제 장소 사진이 아님”을 명시한 분위기용 이미지를 사용한다.

Prompt idea:

> A calm editorial illustration of a neighborhood Korean jjimjilbang entrance near a Seoul subway station at night, warm signage glow, simple urban street, no people, no brand logos, realistic but not specific to an actual venue.

## Do Not Use

- 탈의실 내부 사진
- 탕 내부에서 이용객이 있는 사진
- 블로그 후기 사진 무단 저장본
- 지도 앱 캡처
- 얼굴이 식별되는 휴게공간 사진
- 상업적 허가가 없는 Trip.com/지도/블로그 이미지
